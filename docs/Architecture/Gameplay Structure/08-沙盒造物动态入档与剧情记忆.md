# 08 · 沙盒自创造物、动态入档与剧情记忆

> 静态核查：2026-10-28（基于 2026-10-14 初版演进更新）。7 大设置分组壳层、在册档案卡片网格、`pending_lore` 混型鉴别与 PDA/世界演变采纳闭环、8 类扩展 `<数据>` 自动合成与双向图谱缝合、私产提升步④′提前记账、聊天书逆向回滚账本（`wbJournal`）与分支自动克隆（`branchBookCloner.ts`）、数据补丁楼层内存叠加态（SEAM-03）、三层剧情摘要漏斗（Micro/Meso/Macro）与丢弃顺序修复（`FIX-SUM-01`）以及跨版本战局全保真备份/热更新（`ModalCardUpdate.vue` + `saveBackupService.ts`）均已落地；本次未运行真机。

## 1. 玩家目标与资产生命周期

玩家希望自研科技、特殊建筑、改型载具、装备、重要 NPC 与机娘被长期记住且只影响当前聊天；满意的创造物可以作为私产带到新剧本；长剧情通过三层摘要压缩而不丢失可恢复性；角色卡升级时战局与世界书可一键备份原位恢复。

```text
【沙盒造物】剧情创造 → AI <扩展档案> / <机娘档案> / <事件>新设定 → 本楼暂存
 → 混型鉴别与串行入档队列 → 当前聊天档案书（红警档案·<chatId>，写 wbJournal 逆向快照）
 → 自动合成结构化 <数据> 块 + 双向图谱缝合 + 系统目录防重派生 codex
 → 玩家主动提升（步④′提前记账 $promoted） → 独立私产书 → 跨聊天启用

【三层摘要】逐楼 <摘要> → micro_summaries（Micro）
 → 每20楼归并中摘要 摘要·001-020（Meso，depth=4）
 → 每4段中摘要归并大摘要 摘要·大·001-080（Macro，depth=5，子中摘要降为绿灯）
 → 丢弃时先 unhideRange 解隐楼层、成功后再删世界书条目（FIX-SUM-01）
```

## 2. 实际入口与五条归档管道

### 2.1 中控顶栏与模态框分层入口

- **【档案】主弹窗（`ModalArchive.vue`）**：
  - **主视图**为基于 `useArchiveIndex.ts` + `archiveIndex.ts` 的**在册档案卡片网格**（支持 `全部分类 / 机娘 / NPC人物 / 人员 / 科技 / 建筑 / 载具 / 装备 / 其他·阵营` 筛选、关键词检索与点击 `openDetail` 查看详情）；
  - **底部可折叠抽屉**承载 `PanelArchive.vue`（旧版《EVA·动态档案》兼容归档与历史回退孤儿清理）。
- **【设置】主弹窗（`ModalSettings.vue` + `SettingsShell.vue` 7 大一级分组 + 顶部 `pages` 子页签）**：
  1. `env`（**环境**）：阵营配色、停靠模式、自动生效开关（`autoApply`）、动效、楼层标签自愈、**预设提示词托管（`PRESET GUARD`，`presetPromptManager.ts`）**；
  2. `feedforward`（**参谋前馈**）：前馈策略与注入预览（`PanelFeedforwardSettings.vue`）、**剧情摘要（`PanelSummaries.vue`）**；
  3. `world-evo`（**世界演变**）：活跃演化 L1 与历史卷宗 L2/L3 一键入书（`PanelWorldEvolution.vue`）；
  4. `filing`（**归档与补丁**）：旧设定归档（`PanelArchive.vue`）、机娘入档（`PanelGirlFiling.vue`）、扩展与提升（`PanelExpansionFiling.vue`）、数据补丁（`PanelDataPatches.vue`）；
  5. `parse`（**解析**）：解析修复（`PanelParseRepair.vue`）、别名词典（`PanelAliasDict.vue`）；
  6. `dlc`（**DLC 与备份**）：世界书开关（`PanelWorldbookToggle.vue`）、导出与存档（`PanelExportSave.vue`）、已装管理与导入安装（`PanelDlcManager.vue`）；
  7. `debug`（**调试沙盒**）：完整性自检（`PanelIntegrityCheck.vue`）、调试沙盒、数据流监控四镜片（`ModalDataFlowInspector.vue`）、性能监控。
- **【版本热更新向导】（`ModalCardUpdate.vue`）**：由 `cardUpdateEngine.ts` + `saveBackupService.ts` 驱动，检测 `breaking_save / save_schema` 跨代风险并强制先执行含主书与聊天档案书的全保真备份与原位恢复。

### 2.2 五条归档管道职责边界

| 管道 | 源数据与触发 | 落地目标与核心机制 |
|---|---|---|
| **A. 扩展档案管线** | `<扩展档案>` 及 `pending_lore` 中 `tag === '图鉴'` 的非势力项 → `pending_expansions` | `expansionFiler.fileExpansion` 写入当前聊天书 `红警档案·<chatId>`（8 类分段，`order >= 70000`），自动合成 `<数据>` 块、双向图谱缝合，经 `isDuplicateOfSystemCatalog` 防重后派生 `codex` |
| **B. 机娘档案管线** | `<机娘档案>` → `pending_lore`（经 `isGirlDossierEntry` 鉴别） | `girlFiler.fileDossier` 单书双段写入当前聊天书 `红警档案·<chatId>`（`CTRL-CHATBOOK-01`），与 `expansionAutoFiler` 共享 `enqueueAutoFileTask` 全局串行队列 |
| **C. PDA/世界演变新设定管线** | `<事件>` 新实体 / 情报归档 / `PanelWorldEvolution` L1·L2 卷宗 → `pending_lore` | `PdaWindowFrame.vue`（`onAdoptLore`）调用 `pendingLoreGate.confirmAndCommitPendingLore` 写入聊天书 `实体·${kind}·${name}`，`kind === '势力'` 时同步追加 `stat_data.factions` |
| **D. 旧版兼容与孤儿清理** | `PanelArchive.vue` + `dlcArchiveOrphan.ts` | 勾选写入全局《`EVA·动态档案`》或扫描清理历史回退产生的孤儿词条 |
| **E. 三层剧情摘要管线** | `<摘要>` → `micro_summaries`；`generate_raw` 或 `summaryRunner.ts` 委托主模型产出 `<中摘要>/<大摘要>` → `pending_summaries` | `summaryFiler.adoptSummary`（或 `floorObservers` 自动确认）写入聊天书 `摘要·XXX-YYY`（`depth=4`）或 `摘要·大·XXX-YYY`（`depth=5`），按策略隐藏楼层 |

## 3. `pending_lore` 混型隔离、8 类扩展合成与双向图谱缝合

### 3.1 `pending_lore` 混型暂存隔离与 PDA 采纳闭环（闭合旧版 §8 风险）

- **机娘严格鉴别**：`girlFiler.ts` 新增 `isGirlDossierEntry(item)` 鉴别器，阻断事件/势力等非机娘混型条目进入 `fileDossier`；`girlAutoFiler.ts` 入档后在 `applyFiledGirlsToStatData` 中原样保留非机娘项。
- **图鉴扩展自动合流**：`expansionAutoFiler.ts` 的 `collectPendingExpansionsFromSnapshot` 自动提取 `pending_lore` 中 `tag === '图鉴'` 的非势力扩展项合流入档，并与 `girlAutoFiler` 共享串行锁 `enqueueAutoFileTask`。
- **PDA 与世界演变真实写书核销**：`PdaWindowFrame.vue` 已接通 `pendingLoreGate.ts` 的 `confirmAndCommitPendingLore`，写书成功后再经 `updateFloorVars` 核销 `pending_lore`，彻底闭合了旧版“PDA 采纳只有本地隐藏、父级无消费者”的断口。

### 3.2 8 类扩展、结构化 `<数据>` 自动合成与系统目录防重（`expansionFiler.ts`）

- **8 大扩展类别**：`['人物', '科技', '建筑', '载具', '人员', '装备', '地点', '势力']`（`PanelExpansionFiling.vue` 支持 `+ 手动建档`）。
- **结构化 `<数据>` 自动推导合成**：当 `<扩展档案>` 未显式携带 `d.data` 时，`buildStructuredExpansionDataObject` 根据 `kind` 与 `params` 自动合成符合 `WorldbookDataBlockSchema` 的 `<数据>` 块（`人物 / 地点 / 势力` 严禁生成产线数据块），并通过 `stripMetaJargonLines` 剥离元语言、`sanitizeWorldbookKeys` 净化泛词触发词（上限 8 个）。
- **系统目录防重（`isDuplicateOfSystemCatalog`）**：拦截首发 8 角色（`BUILTIN_ROSTER_PERSONNEL_NAMES`）与可信度 `>=0.85/0.92` 的系统固有目录实体重复写入动态 `codex`。
- **聊天书双向图谱缝合（`linkExpansionGraph`，CHATBOOK-GRAPH-01）**：在聊天书内自动将新科技/新建筑与解锁的新载具/新装备执行双向 `strategy.keys` 与正文 `· 衍生解锁实体` 缝合。

## 4. 聊天书三重守卫、逆向回滚账本（`wbJournal`）与分支自动克隆

- **三重写前守卫（`chatBookBinding.ts`）**：校验事务聊天身份未变、当前绑定非空、绑定书存在（支持首次写入惰性建书）。
- **逆向回滚账本与分支克隆隔离（`branchBookCloner.ts` + `floorObservers.ts`）**：
  - 自动入档写书前后调用 `snapshotWorldbookEntriesBeforeWrite` 与 `recordWorldbookMutationsFromDiff`，在 `$timeline.floors[f_X].swipes[s_Y].wbJournal` 记录条目级逆向快照；
  - 删楼时执行 `rollbackWorldbookMutations` 逆向回滚；Swipe 切换时执行 `reconcileSwipeWorldbookTransition` 双向对账；
  - 触发 SillyTavern `/branch` 分支聊天时，`ensureBranchWorldbookIsolation` 自动克隆独立世界书 `红警档案·..._branch` 并裁剪高于分叉楼层的变更与越界摘要。

## 5. 数据补丁楼层内存叠加态（SEAM-03）与私产提升步④′提前记账

### 5.1 数据补丁三路路由与失败指纹防死循环

- **楼层内存叠加态（`preferTimelineOverlay: true`，SEAM-03）**：`worldbookDataFiler.ts` 对命中系统全局主设定书的补丁默认走 `TIMELINE_OVERLAY`，仅记入 `stat_data.applied_data_patches` 供 `useCatalog` 内存派生叠加，零全局世界书文件污染。
- **失败指纹防死循环（`patchFailFingerprint.ts`）**：记录失败补丁双种子 FNV-1a 指纹（按 `chatId` 分桶），`autoApply` 遇同指纹自动跳过，手动点击「立即生效」不受限；人工裁决同步记入 `$timeline` 的 `PATCH_DECISION` 过程量供重解析重放。

### 5.2 私产提升（`promoteEntry`）半程态窗口闭合

`expansionFiler.ts`（L1685–1715）在步④复验目标私产书持久化通过后、**步⑤删聊天书源条目之前**新增 **步④′ 提前调用 `recordPromoted` 写入 `$promoted`**，并在步⑤删源后立即 `flushWorldbook(sourceChatBook)`，闭合了旧版步⑤中断无法被 `detectHalfStates` 检出的窗口；同时新增 `promotedRecordStatus` 将目标私产书已删的悬挂记录降级为 `forkStale` 提示。

## 6. 三层剧情摘要漏斗（Micro / Meso / Macro）与丢弃顺序修复（`FIX-SUM-01`）

- **三层漏斗与双通道生成（`summaryFiler.ts` + `summaryRunner.ts`）**：
  1. **小摘要（Micro）**：逐楼 `<摘要>/<summary>` 写入 `stat_data.micro_summaries`（楼层底部由 `floorCardSummary.ts` 渲染折叠胶囊卡片）；
  2. **中摘要（Meso）**：每 20 楼通过 `generate_raw` 独立端点或 `summaryRunner.ts`（`delegate_main` 注入 `redalert_summary_delegation_feed` 委托主 LLM）产出 `<中摘要>`，入书为 `摘要·001-020`（`depth=4`，默认 `constant` 蓝灯）；
  3. **大摘要（Macro）**：每 4 段中摘要归并为 `摘要·大·001-080`（`depth=5`），并将被覆盖的子中摘要降级为 `selective` 绿灯（标记 `extra.coveredByMacro`）。
- **自动确认与逆序安全丢弃（闭合旧版 §7 黑洞风险）**：
  - `isHidingGateApproved` 与 `getSummaryAutoConfirm` 默认开启（`true`），由 `floorObservers.ts` 的 `autoConfirmPendingSummariesIfEnabled` 自动采纳入书；
  - **丢弃顺序修复（`FIX-SUM-01`）**：`discardSummary` 改为**先调用 `unhideRange(from, to)` 解隐区间楼层，成功后再执行 `deleteWorldbookEntries` 删除世界书摘要条目**（解隐失败直接中止删条，杜绝“摘要已删但原文仍隐藏”的黑洞段）；删楼/分支时 `reconcileChatSummariesAboveFloor` 自动清理越界摘要并解隐楼层。
