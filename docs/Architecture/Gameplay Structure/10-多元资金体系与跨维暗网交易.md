## 4. `<暗网>` 顶层平级协议与九大标准交割动作

### 4.1 语法兼容与顶层容错

- **同义标签兼容**：[`darknetEngine.ts`](../../../mvu指挥系统/src/红警指挥系统/engines/darknetEngine.ts)（L40）与 [`tavernRegexPipeline.ts`](../../../mvu指挥系统/src/红警指挥系统/worldbook/tavernRegexPipeline.ts)（L458）同时识别 `<暗网>`、`<暗网订单>`、`<暗网采购>`、`<暗网交易>`、`<黑市>`、`<黑市订单>`、`<黑市交易>`（`display: true, prompt: false`）；另注册 `ECONOMY_CHAINS_REGEX_ID` 水合 `<资金链>` 楼层卡。
- **结构与资源映射容错**：若模型漏写 `本轮交割:` 外层键而直接输出订单数组/对象，`applyDarknetBlockToState` 自动包装；`资源扣减 / 资源映射` 支持标准 `{柱, 键, 数量}`、嵌套 `{柱名: {小类名: 数量}}` 或简写 `{小类名: 数量}`（由 `inferResourcePillarAndKey` 自动推断六柱并归一纳米别名）。

### 4.2 九大标准交割动作与二轮防呆守卫（`CanonicalSettlementAction`）

| 动作枚举（及容错同义词） | `darknetEngine.ts` 确定性行为 | 三色门防作弊与二轮加固守卫 |
|---|---|---|
| `售出实物`（`投递实物 / 出售物资`） | 校验并扣减对应六柱库存（`tryDeductResource`），正数 `资金变动` 加至 `economy.credits` 并记入 `ledger` | 库存不足（会导致 `<0`）时刚性阻断该笔交割并记 🔴/🟡 告警，绝不凭空加钱 |
| `售出信息`（`上传情报 / 售出数据`） | 核验 `查重键`（缺省取归一化 `标的` 名）是否已在 `sold_intel_ids` 中；首发追加至 `sold_intel_ids` 并入账 | 已存在于 `sold_intel_ids` 时拦截为重复售卖，资金变动强制归 `0` |
| `完成悬赏`（`交割悬赏`） | 将对应悬赏标为 `已完成`，登记入 `completed_bounty_ids`，增加 `credits` 并处理可选 `资源扣减` | 命中 `completed_bounty_ids` 的悬赏永久防重复领赏（不受 `ledger` 20 条上限裁剪影响） |
| `购买商品`（`直购商品`） | 校验 `credits` 与商品 `库存`；扣款、减库存，含 `资源映射` 则充入六柱，否则按类别入库 `forces` | `credits` 不足或商品库存为 `0` 时阻断交割 |
| `竞拍出价`（`参与竞拍 / 加价`） | 更新拍品 `当前最高价 / 领先方 / 轮次`，**落槌前暂不扣减 `credits`** | 出价低于当前最高价仅发 🟡 提示不降价；仅当我方领先（`isPlayerParty`）且超现有资金时触发验资预警（`BUG-R2-10`） |
| `拍卖竞得落槌`（`竞拍成交`） | 校验并扣减 `credits`，拍品置 `已成交`，登记入 `settled_auction_ids`，自动入库 `economy.resources` 或 `forces.vehicles/troops/equipment` | 命中 `settled_auction_ids` 防同一拍品重复扣款 |
| `拍卖送拍成交`（`送拍落槌`） | 拍品置 `已成交`，登记入 `settled_auction_ids`，将净成交额加至 `economy.credits` | 防同一送拍编号重复入账 |
| `上架送拍`（`委托送拍`） | 若含 `资源扣减` 先行锁定实扣实物（标 `consign_deducted: true`），在 `当期拍卖` 追加我方拍品 | 库存不足时拒绝送拍 |
| **`撤拍`（新增第 9 动作：`取消送拍 / 主动撤拍 / 流拍`）** | 校验拍品属我方且未结算/未退回；若已托管实扣 `resource_map`，调用 `creditResourceMap` **全额退回六柱库存**，状态置 `cancelled / passed`，标 `refunded: true` 并记入 `settled_auction_ids` | 防止主动撤拍或流拍吞没玩家托管实物，且防重复退库 |

> **拍卖列表状态直改自动联动（`BUG-R2-10 / BUG-R2-23`）**：即使 LLM 未在 `本轮交割` 单独写动作，只要在 `当期拍卖` 列表中直接将我方送拍品设为 `bidding`（自动扣托管库存）、设为 `passed / cancelled`（自动退库）或将拍品设为 `sold`（块尾第 8 步自动补做送拍入账或竞得扣款入库），引擎均会自动完成闭环。
