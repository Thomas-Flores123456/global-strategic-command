## 一、先读结论

本项目是 **聊天叙事驱动 + 程序规则约束结算 + 中控操作与状态投影（辅以显式受控前端直写通道）** 的混合玩法系统，现同时兼容传统 SillyTavern（角色脚本 iframe）与 TauriTavern（ABI v1 原生扩展 / 角色脚本双轨）。

相比 `2026-10-14` 初版快照，当前代码库已完成大量核心闭环：
- **已全量接通的主干**：双宿主桥接与双轨楼层卡水合、五大分类建造网格与三视图建筑沙盘（含三环相对坐标与 Dagre 五大体系蓝图）、六动词 `instantMode` 即时日程调度、满工时系统主权自动交割（`BUG-R2-20`）与部队/建筑自动入库、30 项战略协议（含尤里 3 轨 12 项）与 9 座三阵营院所协同、V1 完工 47 项单位/建筑原位升格与 V2 纳米实扣、FD-27 天基航天四域 48 槽 SVG 蓝图画布与 `spaceEngine.ts`、14 动词事件门与 `FD-51` 三轨资金链（含局部天候与 `PdaTabQuests`）、五大合法资金阀门与 `<暗网>` 9 动作交割及双页签终端、开局 1～3 阵营折算与暴露/民心双驱引擎、`ModalMechaGirl.vue` 全角色正史动态回读与聊天绑定书单书双段入档、三层剧情摘要漏斗与 `wbJournal` 分支克隆回滚、跨版本战局全保真备份与热更新。
- **仍属远期演进或局部待补的边界**：单批次废料 L0–L3 进炉工期配方台、T3 巨构 `RECIPE-01` 原料代偿抵扣、`<当前工程日程>` 中独立的 `◆ 战区天基与航天态势` 前馈节、`settleFloor` 主循环向 `applyGridConstraints` 透传载具/势力参数、88+ 机娘个体技能的细粒度战斗公式化，以及 UTO `tickTaskOrchestration` 全面替换 `settleWithTwoStage`。

最容易混淆的三个层次：
1. **设计已定案**：表明规则方向已确认，不证明代码已写。
2. **静态调用链已接通**：表明入口到处理在当前源码中可追踪，不证明真实宿主已验。
3. **完整端到端验收（`driver-accepted`）**：还需模型输出、宿主事件、账实持久化和驾驶员人工确认。

本次只交付前两层的最新架构梳理，**不授予运行通过或 `driver-accepted`**。
