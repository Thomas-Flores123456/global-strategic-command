# 06 · 航天工业与天基工程

> 静态核查：2026-10-28（基于 2026-10-14 初版演进更新）。天基与航天工业已形成**「传统 V1/V2 轨道工程轨 + FD-27 专属天基航天与四域蓝图画布轨」双轨并行闭环**：`Schema.space`、`spaceEngine.ts`、工程弹窗 `🚀 天基航天` 第三主域、四域 48 槽 SVG 蓝图画布（`SpaceBlueprintCanvas.vue`）、`scene.aerospace.mcc` 三视角舞台、14 项可制造航天装备排产、双源载荷装箭与 `<航天合同>` 楼层卡片正则水合（`SpaceContractCard.vue`）均已静态接通；仅 `<当前工程日程>` 中的独立 `◆ 战区天基与航天态势` 前馈节尚未单列。本次未运行真机。

## 1. 玩法目标与玩家侧可见入口

航天系统是一套工序型战役工程，玩家决定 **送什么、从哪里送、用什么火箭构型、送往何轨道、如何配置天基拓扑与处理气象/运力约束**。

### 1.1 工程中心弹窗第三主域（`ModalEngineering.vue`）

顶栏已从原有的“短期改装 / 长期巨构”扩展为三域切换：**`短期改装 (short)` / `长期巨构 (long)` / `🚀 天基航天 (space)`**，并在顶栏右侧常驻 `eng-space-status-bar`（实时展示在轨载荷数、可复用助推器数、活跃/总合同数）。

切至 `space` 域时，左侧导航栏提供 **4 个天基子视图（`activeSpaceSubView`）**：
1. **`📡 测控与发射台 (mcc)`**：
   - 顶层内嵌 `EngSceneView.vue` 渲染 `scene.aerospace.mcc`（支持 `pad` 发射场总览、`leo` 近地轨道、`tli` 地月深空 **3 个空间视角切换**与 5 个阶段热点）；
   - 中部提供天地月多发射中心切换栏（支持按基地切换及解锁近地轨道船坞 `orbital_dock` / 月面发射场 `lunar_surface`）；
   - 下方分左右两栏：左栏为发射中心 `4→8→12` 槽拓扑画布，右栏为 **3 页签工作台**（`🏗️ 中心扩建与选配`、`🏭 航天装备制造`、`📜 发射合同与排期`）。
2. **`🌐 轨道星座组网 (constellation)`**：挂载 `SpaceBlueprintCanvas.vue`（`domain="constellation"`，LEO 低轨 4 槽 + SSO 极轨 4 槽 + GEO 高轨 4 槽 = 12 槽画布）。
3. **`🛰️ 空间站组装 (station)`**：挂载 `SpaceBlueprintCanvas.vue`（`domain="station"`，9 槽 Tier-1 十字主干 + 3 槽 Tier-2 深空外延 = 12 槽画布）。
4. **`🌕 月球基地建设 (lunar)`**：挂载 `SpaceBlueprintCanvas.vue`（`domain="lunar"`，8 槽环形山内圈 + 4 槽 Tier-2 外环原位矿脉 = 12 槽画布）。

### 1.2 楼层内嵌航天合同终端卡（`SpaceContractCard.vue` / `floorCardMounts.ts`）

`tavernRegexPipeline.ts` 内置 `AEROSPACE_CONTRACT_REGEX_ID = 'tavernweave.system.aerospace-contract-iframe.v1'`，拦截 `<航天合同>` / `<航天>` / `<天基>` / `<太空>` / `<发射中心>` 并包裹为 `aerospace-contract` Display 壳；`floorCardHydrator.ts` 支持 `space-contract` 与 `aerospace-contract` 双标识水合，渲染运载火箭、有效载荷、发射中心、载荷来源、目标插槽、报酬回款、一级助推器回收模式与气象窗口提示，并提供一键「🚀 批准点火发射」填入聊天框能力。

## 2. 三条完整操作链（从制造/规划到入轨结算）

```text
【链A：四域蓝图规划】SpaceBlueprintCanvas 选槽配构件 → 电力/维生双平衡与羁绊预演
   ├─ 顶栏「📋 提交天基蓝图指令」 → 填框 <航天> 天基蓝图
   └─ 单节点「🏗️ 立即扩建」或「🚀 立即建造并发射」 → 跳回 mcc 预填 contractPreset + 填框指令

【链B：装备排产与合同发射】三大航天制造中心排产 14 项发动机/箭体/载荷 → 入库 space.equipment_stock
   → 📜 发射合同与排期（D7-B 双源隔离：自家库存载荷 vs 外部商业委托 commercial_orders）
   → 选发射中心/火箭/轨道/助推回收 → 实时验算运力/气象/选址乘数 → 下达 <航天合同>
   → parsePipeline + settleFloor(S2g_SPACE) → settleSpaceOperations 门控校验、扣库、返库、回款、点亮插槽与入轨

【链C：V1/V2 重大轨道工程】世界书 project 条目 → eng.orbital 轨道槽 → projectEngine / projectEngineV2Core
```

### 2.1 操作链 A：天基四域交互蓝图规划与节点建造/发射链

- 玩家在 `station / constellation / lunar / launch_center` 画布点击拓扑插槽，右侧 `sbc-inspector` 抽屉过滤出接口匹配（`allowedInterfaces`）的构件，实时预演 `⚡ 电力收支 (kW)` 与 `🫧 维生/热控冗余`、组网羁绊点亮及三重渐进展开门控（父节点建成门、`requiresExpansionHub` 扩展枢纽门、`requiresRoverSurvey` 月面探测车勘探门）。
- 点击顶栏「📋 提交天基蓝图指令」调用 `buildSpaceCanvasBlueprintOrderText` 生成 `【天基蓝图规划令】` + `<航天>` 填框；点击单节点「🚀 立即建造并发射此节点」自动校验发射场就绪、基地气象与最大运力（`massTons <= maxPayloadTons`），一键跳回 `mcc` 预填 `contractPreset` 并填入指令。

### 2.2 操作链 B：14 项装备排产、D7-B 双源载荷装箭与合同点火结算链

- **3 大航天制造中心与 14 项标准化装备（FD-27 D7-A）**：
  - `火箭制造厂`：发动机 3 项（海平面液氧煤油、高空真空液氢液氧、全流量液氧甲烷）+ 箭体级段 4 项（通用捆绑助推器、标准芯一级、高空真空芯二级、远征上面级）；
  - `卫星制造中心`：载荷 4 项（低轨高分光学侦察、高轨红外预警通信、天基多光谱资源勘探、月面无人软着陆器与巡视探测车）；
  - `大型航天器与舱段总装中心`：载荷 3 项（宇宙飞船载荷总成、双级载人登月舱与月面增压车、模块化空间站标准舱段总成）。
  - 在 `mcc` 的 `🏭 航天装备制造` 页签支持未建中心一键立项建造（`buildAeroBuildingConstructCommand`）及已运转中心 `+1 排产 / +4 批量`（`buildAeroEquipmentProduceCommand`），完工后由 `syncAeroEquipmentStock` 自动同步至 `space.equipment_stock`。
- **D7-B 双源载荷隔离与实时验算**：在 `📜 发射合同与排期` 页签严格区分「🛰️ 战区自家载荷（`space.equipment_stock`）」与「💼 外部商业委托（仅读 `space.commercial_orders`，前端零伪造）」，经 `computeContractPayoutPreview` + `evaluateRocketSpec` 实时验算最大运力、载荷超重拦截、气象窗口、选址乘数与可回收助推器加成（`+15%`）。

## 4. Schema 状态切片与底层引擎（`spaceEngine.ts`）

### 4.1 `Schema.space`（`SpaceSlice`，`core/schema.ts` L866–955、L1261）

- `orbital_assets: OrbitalAsset[]`：在轨卫星、星座、空间站舱段、轨道武器与商业载荷名册；
- `contracts: SpaceContract[]`：发射合同与在轨任务（含 `duration_days / elapsed_days / weather_hold_reason / launch_center_id / target_slot / asset_id / mass_t / payload_source`）；
- `reusable_boosters: number`：可复用一级助推器库存；
- `launch_centers: LaunchCenterRecord[]`：FD-27 多发射中心实例（含 `site_type / tier: 1|2|3 / status / mounted_slots`）；
- `completed_slots: Record<string, string>`：已点亮天基画布插槽映射（`slotId -> assetId`）；
- `equipment_stock: Record<string, number>`：14 项可制造航天装备与载荷库存；
- `commercial_orders: SpaceCommercialOrder[]`：FD-27 D7-B 外部商业航天委托订单池。

### 4.2 天地月 6 大选址硬数值与发射中心推导（`spaceEngine.ts`）

| 选址类型 (`site_type`) | 回款乘数 | 运力乘数 | 点火暴露脉冲 | 等级上限与特性 |
|---|---|---|---|---|
| `equatorial_coastal`（赤道滨海） | ×1.20 | ×1.15 | +0.12 | 上限 T3 |
| `inland_canyon`（内陆峡谷） | ×1.00（高轨 ×0.90） | ×1.00（高轨 ×0.90） | +0.05 | 上限 T3 |
| `sea_platform`（海上机动平台） | ×1.20 | ×1.15 | +0.03 | **锁死 T2**，禁升格国家航天城 |
| `high_latitude`（高纬极地） | SSO ×1.25 / GEO ×0.85 | SSO ×1.20 / GEO ×0.80 | +0.06 | 上限 T3 |
| `orbital_dock`（近地轨道船坞） | ×1.50（月面协同 ×1.75） | ×2.00 | +0 | 免疫地面气象，单次耗纳米 50（月面反哺后为 0） |

`deriveLaunchCentersFromState` 自动扫描基地在役航天建筑映射点亮发射中心插槽，推导 `tier`（1/2/3 最大基准运力 `8t / 35t / 65t`）、`isSpaceportCity`（国家航天城小巨构：回款额外 ×1.25、排产效率 ×1.50）与 `isFullReuseStarbase`（两级全复用星舰基地：基准运力升至 `80t`）。

### 4.3 四域 48 槽蓝图注册表与 8 大协同羁绊（`spaceCanvasRegistry.ts`）

- **48 个拓扑插槽**：`station` 12 槽 + `constellation` 12 槽 + `lunar` 12 槽 + `launch_center` 12 槽（`4→8→12` 渐进扩容）。
- **42 枚正典天基构件资产**：空间站 12 枚 + 轨道星座 6 枚 + 月球基地 10 枚（配 `spaceCanvasSvgSymbols.ts` 28 枚军工蓝图风矢量图元与 `registerCustomSvgSymbol` 开放注册口）+ 发射中心 14 枚构件（`LAUNCH_CENTER_ASSETS`）。
