## 4. 当前剩余的静态差距与优先核查项

1. **资金链电网约束的载具/势力参数透传**：`operationEngine.ts` 的 `applyGridConstraints` 已支持 `deps.vehicles` 与 `deps.faction` 核验，但 `settleFloor.ts` 主调用目前仅传入 `chains / bases / nowDay`，需在后续纵切片中补齐 `forces.vehicles` 与 `factions` 透传。
2. **天基态势专属前馈小节**：`planning/scheduleText.ts` 已包含科研、协议、排产回执与 V1/V2 重大工程，但尚未为 `state.space`（在轨卫星名册、助推器库存、合同倒计时与气象挂起）单列 `◆ 战区天基与航天态势` 章节。
3. **协议日产点参谋部加成的公式统一**：`settleFloorPhases.ts` 按乘法 `baseDailyRate * (1 + bonus)` 结算，而 `PanelProtocol.vue` HUD 按加法 `baseRate + bonus` 展示，建议后续统一为同一公式。
4. **单批次废料 L0–L3 进炉配方台与 `RECIPE-01` 巨构原料代偿**：建筑被动日产、商路三轨流式消耗与暗网单笔交割已闭环，但车间级逐批次进炉工期配方与巨构建造吞吐实物抵扣 60%～80% 现金仍属远期演进。
