# 盟军现实与特色武备技术档案考据（FD-49 Phase 1 · REF-ALLY）

- **考据来源**：`A181`（`REF-ALLY`）14 轮 `exa_web_search_exa` 逐项专注检索（涵盖美国陆海空天及北约欧洲、日韩印太同盟现役与 2024–2026 年在研装备公开技术档案）
- **适用范围**：供 `FD-49` Phase 2 之 `PKG-B`（《特色科技·盟军_世界书.json》）与 `PKG-C`（《武备·盟军_世界书.json》）落盘使用
- **核心原则**：
  1. **通用科技优先挂通**：《武备·盟军》141 项有效作战单位必须 100% 挂接《通用·*》系列世界书对应的通用科技 ID，消除 `need_tech: []` 零科技白板；高级型号与盟军独有武备叠加《特色科技·盟军》ID；
  2. **通用职能兵种迁出**：`通信兵`、`炮兵`、`无人机操控兵`、`海军陆战队`、`宪兵`、`特种作战兵`、`自主步兵作战平台`、`外骨骼步兵` 8 项通用职能步兵迁入《通用·人员_世界书.json》共享兵种池，不再保留于盟军专属武备书；
  3. **体制差异化锚点**：盟军武备突出 **STANAG 北约标准化接口、高比功率航改燃气轮机/精密涡扇、AESA 氮化镓有源相控阵、Link-16/MADL/CEC 协同交战网络、激光/GPS 复合精密制导与隐身低可探测构型**，与苏俄武备的大口径重炮、超音速重型防区外导弹、宽轨铁路与抗寒粗犷冗余形成鲜明对比。

## 一、单兵与特种作战装备谱系（7 项保留盟军专属单兵）

### 1. 盟军大兵（Allied GI · `ally.infantry.gi`）
- **现实技术锚点**：美军标准步兵火力组，列装 `M4A1 5.56×45mm NATO` 卡宾枪 / `XM7 6.8×51mm (.277 Fury)` 下一代班组步枪（SIG Sauer MCX Spear，配 `XM157` 1-8×30 综合火控光学瞄具，内置激光测距、弹道计算机与数字罗盘）及 `M249 SAW` / `XM250 6.8mm` 班用轻机枪。单兵携行 `ESAPI Rev.G` 碳化硼陶瓷插板防弹衣与 `ENVG-B` 双目融合夜视仪。
- **部署体制差异**：依托北约 `STANAG 4172/4694` 导轨与弹匣通用体系，展开沙袋掩体立姿依托射击时依靠 `XM157` 火控解算抑制中远距散布；区别于苏军动员兵的 `5.45×39mm` 冲锋压制体制。
- **科技挂接建议**：`need_tech: ["枪械工程学", "单兵防护工程学"]`

### 2. 重装大兵（Guardian GI · `ally.infantry.guardian_gi`）
- **现实技术锚点**：列装 `FGM-148F Javelin（标枪）` 顶攻反坦克导弹（焦平面红外成像导引头 + 串联聚能破甲战斗部，射程 2,500–4,000m，可击穿 800mm RHA 叠加 ERA）与 `FIM-92K Stinger（毒刺）` 红外/紫外双色导引便携防空导弹（含近炸引信与数据链告警接收机）。
- **部署体制差异**：发射后不管（Fire-and-Forget）热成像软发射体制，可在建筑物内部发射，但红外导引头冷却氩气瓶（BCU）与高价位焦平面阵列依赖精密光电供应链；区别于苏军 `RPG-29 / 9M133 Kornet` 的大口径激光驾束硬穿深体制。
- **科技挂接建议**：`need_tech: ["反装甲武备学", "单兵防空学"]`

### 3. 盟军军犬（Allied Attack Dog · `ally.infantry.attack_dog`）

- **科技挂接建议**：`need_tech: ["单兵战技学", "轻步兵战具学"]`

### 4. 火箭飞行兵（Rocketeer · `ally.infantry.rocketeer`）
