## 〇、一句话总纲

**position 决定"注入在哪"，order 决定"同桶内谁排前、谁先死"；depth 只在 @Depth 通道内生效。**
治理立场：全库 `position=0` 单注入块 + order 千位分带**维持为项目默认铁律**；`@Depth` 仅作为**白名单例外通道**，服务极少数"必须贴近对话尾部"的条目。治理目标是把例外钉窄，不是全面分层。

## 三、第一轮决策（INJ-A · 全部 proposed，待驾驶员裁决）

### INJ-D1 默认铁律：全库 position=0 单注入块是否立为项目默认？

- **甲（推荐）**：默认 `position=0` 立为铁律；@Depth 仅作白名单例外通道。理由：现状运转良好、单序可预测、漂移面最小；直接继承姊妹卷"不要用 depth 制造独立 order 空间"的纪律。
- 乙：开放多 position 自由选择，每条按需挑。代价：872 条注入拓扑失去单序可预测性，每条编写都要做一次定位决策，漂移与审计成本转嫁给全书库。
- 丙：全库迁 @Depth 多层分层。预否决理由：F7/F8 证明 depth 既不豁免 budget 也不改变存活竞争域，纯增复杂度、零存活收益，还废掉既有 order 分带语义。

### INJ-D2 @Depth 白名单准入类别：哪些条目类型够格走例外通道？

- **提案准入**：① **实时状态/警报/态势提示**（内容随轮变化，变了就必须立刻被模型读到）；② **本轮强指令/文风守则**（必须"最后被读到"的近因指令）。
- **提案不准入**：百科/设定/背景/势力/地理/科技等一切知识类——**铁律：知识类一律 position=0**。
- 准入判据一句话："这条内容是否**每轮都可能变、且一变就必须优先于既有知识被照办**？"是 → 可进白名单；否 → position=0。

### INJ-D3 例外条目的钉死参数包

- **甲（推荐）**：@Depth 例外统一 `depth=2、role=0(system)`；order 仍走千位分带参与存活竞争（子带值留 INJ-B 定，暂议 95000+），**不豁免 budget**。
- 乙：按类别双档——警报 `depth=1`、常态提示 `depth=2`；role 恒 system。
- 边界说明：`depth=0` 不建议（与最新消息贴身抢位，易被模型当对话正文而非指令）；`role` 恒 system（伪装 user/assistant 无必要且扩大漂移面）；`role` 变化即换注入桶（F5），非必要不新增桶。

### INJ-D4（可并入 INJ-B 再议）：是否引入条目级 `ignoreBudget` 作"警报必须存活"豁免开关

- **甲（推荐）**：暂不引入，白名单条目先靠高 order 保命，留观察期。
- 乙：白名单条目同时开 `ignoreBudget`。代价：绕开 budget 硬闸门（技巧7 的最终兜底失效），若引入必须配更严的白名单上限（如全局 ≤2 条）。

### 第一轮修正（2026-09-19 · 驾驶员提出"重要信息提权"方向）

> 驾驶员原意：重要的信息可以提权，甚至干脆放到最重要的地方——例如红警系统本身的信息和法则、世界观背景等。

**评估：「重要」必须拆成两轴，两种重要对应完全不同的处置。**

- **服从型信息**（红警系统法则、禁令、文风铁律、世界宪法级基石）：价值 = 每轮都被遵守。此类提权**有效**。position=0 块底虽紧贴角色定义（F4），但长对话中角色定义距生成点隔着数万 token 的聊天史，法则实际落入"中段弱注意力区"（lost-in-the-middle 为业界实测现象；本栈具体收益 🟡模型相关，待实测）。生态先例支持：交错宙域 2.6.2 即"规则类常亮 + 浅深度前置"（§1 旁证）。
- **检索型信息**（世界观背景、势力、编年史、地理）：价值 = 相关时在场。此类提权**无效且有害**：尾部位置是稀缺资源，背景常驻尾部 = 每轮白烧 token + 挤占真正需要近因的内容 + 注入聊天区存在"被模型当成剧情正文"的风险（role=system 可缓解不可消除）。检索型的正确待遇 = 关键词门控 + 高 order 保命，即现有优化体系。

**提权四档**（position 只是第 3 档，勿混为一谈）：

| 档 | 旋钮 | 解决什么 |
|---|---|---|
| 1 | `constant=true` | 在不在（每轮必在） |
| 2 | `order` 高带 | 死了没 / 桶内排哪（F4/F8：触顶高 order 存活、块底贴角色定义） |
| 3 | `position=@Depth` 浅深度 | 离生成点多近（近因性） |
| 4 | 容器外：preset 主提示 / 角色卡 description | 真正的最高位：恒定在场、不受世界书 budget 约束；但脱离 22 本世界书管理面，跨容器治理成本高 |

注：红警系统法则属跨世界不变的宪法层，第 4 档是其天花板；是否越容器属更大架构问题。

**修订决策（替换原 INJ-D2 框架，待驾驶员裁决）：**

- **INJ-D2′ 提权方向**：**甲（推荐）服从/检索二分**——法则基石提权、背景不提权；例外通道扩为两层：**基石层**（constant + @Depth 2–4 + role=system + 高 order，严格控量、少而短）+ **动态层**（@Depth 1–2，警报/本轮强指令）；知识类 position=0 铁律不动。乙：法则+背景一起提权（不推荐，理由见上）。丙：都不提权，回原案。
- **INJ-D3′ 基石层参数包**（若 D2′ 选甲）：depth 取 2/3/4 哪档；基石条目数量与单条体量上限（原则"少而短"，具体数值进 INJ-B 配套）；order 子带暂议 95000+。
- **INJ-D5 容器级提权（preset/角色卡）**：甲（推荐）进 Parking Lot，本规范不管跨容器；乙：纳入本规范加议（INJ-A 预算将吃紧）。

### 第一轮对抗审查（2026-09-20 · Claude 复核 · 生成/评估分离，承 A0 第 5 层）

> 说明：上节"第一轮修正"由 kimi 提出，骨架（服从/检索二分、提权四档、拦背景提权、诚实标注）成立并保留。本节是独立审查视角，只补两处**证据缺口**与一处**论证纠错**，不覆盖 kimi 贡献。

**纠错 C-1（论证方向错误，源码可证）**：kimi 称"法则在 position=0 块底，长对话沉进**中段弱区**"。此论证方向错误。F11 源码实证：`position=0(↑Char)` 内容经 story string 拼在**聊天历史之前**，落在整段 prompt 的**开头强区**；lost-in-the-middle 是 U 型（两端强、中间弱），"距生成点远"≠"在中段"，开头永远是开头。

- 连带结论修正：@Depth 不是"从弱区救到强区"，而是"在**结尾再占一个强区**"——本质是 **双端占位（token 翻倍）**，只值得给最需近因的少数条目，不是默认动作。
- 给 kimi 补一个公道：**静态**宪法走 @Depth **不破坏 prompt 缓存**（内容每轮一致、深度固定）；真正毁缓存的是每楼变的动态摘要。故双端补位对静态宪法安全，代价仅为 token。

**证据补 C-2（存量真相，kimi 未扫库）**：F12 扫全库 13 条常驻发现——① @Depth 动态层**已是既有实践**（异能穿越模拟器 uid17/18/19），故本议题应称"规整既有例外"而非"新引入通道"；② **真正的 bug**：服从型宪法（禁令/机娘法则）`order=100` 与检索型背景（纳米/电力/科技树）**完全平级**。驾驶员"重要信息该提权"的直觉**在存量里根本没被执行**——法则连 order 都没提。

**据此的最小改动纠正（承 A0"最简可维护/最少变更"）**：先修 order 平级 bug 是**纯 order 调整、position 不动、风险最低**的第一手；kimi 直接跳 @Depth 基石层，跳过了这个更便宜的中间档。

**提权三档递进（替换 kimi"四档并列"为"递进决策序"）：**

| 档 | 动作 | 风险 | 适用 |
|---|---|---|---|
| **①先做** | **order 提权**：服从型宪法从 100 提到独立高带（暂议 95000+），与背景拉开 | 极低（既有 order 体系内，position 不动，不碰拓扑） | 全部服从型法则/禁令/文风铁律 |
| **②可选** | **@Depth 双端补位**：position=0 保留 + 结尾浅深度再补一份 | 中（token 翻倍，须严格控量） | 仅"必须最后被读到"的极少数：输出格式、本轮强指令、文风守则 |
| **③不做** | 容器外 preset / 角色卡 description（真正天花板） | 跨容器治理成本高 | 跨世界不变的宪法层（→ Parking Lot） |

**作用域提醒**：22 本为不同世界排他切换。"红警系统法则"主要集中于 `异能穿越模拟器`；"世界观背景"分散在各 `世界适配` 书。落地是**按书分类动**，非全库 22 本统一动。

**修订决策（替换 INJ-D2′，待驾驶员裁决）：**

- **INJ-D2″ 提权阶梯**：**甲（Claude 建议）三档递进**（①order 先行 → ②@Depth 双端补位给少数 → ③容器外入 Parking）／乙（kimi 原案 D2′ 甲）法则整体上 @Depth 基石层／丙 回原案只放行动态层。
