## 阶段 G · 存档导入导出闭环 + 开局有效性检查

**输入**：阶段 F 产物（完整向导）
**允许修改**：`src/开场启动器/`、`src/红警指挥系统/panels/PanelSystem.vue`（仅加导出按钮）
**禁止**：修改 schema/store/parsePipeline/useParse/systemCheck 逻辑

### 退出条件
1. 指挥系统系统 tab "导出存档到剪贴板"按钮：点击 → toast "已复制" → 剪贴板含合法 JSON
2. 启动器粘贴框：粘入合法 JSON → Step 1-2 自动回填（资金/地点/日期/科技/暴露度，难度自动切 custom）→ 可微调后发射；`$boot.importedFrom` 记录来源
3. 粘入非法 JSON → 红框提示"格式不对"，不影响手动填写
4. **开局有效性检查（驾驶员追加，语义已二次修正）**：⚠ 驾驶员裁定铁律：**绑定角色卡 ≠ 启用；启用 = 加入全局启用列表（World Info Active，即 rebindGlobalWorldbooks）**。Step4 发射区上方"开局体检"块——对照 worldId→世界书清单检查 `getGlobalWorldbookNames()`；全部启用显绿 ✓；缺失时列出 + **"一键启用世界书"按钮亮起**（`rebindGlobalWorldbooks(当前全局列表 ∪ 缺失书，去重保序)`，他卡/用户自有书原样保留）；书文件不在酒馆（`getWorldbookNames()` 查无）时提示"缺书文件需导入"不假装能修；检查不阻塞发射；EVA·动态档案 required:false
5. **G4 · 指挥系统存量"启用"语义翻新（驾驶员点名修正）**：PanelSystem.vue 世界书总开关区与 dlcInstaller.ts 启停函数组（约 560-661 行 enable/disable/applyEnableList）的"启用=绑卡 additional"改为"启用=全局启用列表"；B1 管辖权原则平移（只增删面板管的书，全局列表内其他书原样保留）；文案同步更新。**不动**：dlcInstaller 安装/卸载/归档的绑卡逻辑（绑定作为"本卡资产归属"记录保留）、useParse 权威名单读绑定、systemCheck R10。DLC 安装后自动全局启用 → Parking Lot
6. 真机闭环：聊天 A 导出 → 新聊天 B 启动器粘入 → 发射 → 继承进度；体检：全局列表缺书 → 按钮亮起 → 一键启用 → 变绿；总开关区全启用/停用往返
7. vitest 覆盖：导出格式、导入解析回填、非法输入防御、checkWorldbookBinding 纯函数（齐/缺/无文件/可选书缺失四态）
8. `pnpm build` 绿

### API 事实（真机已探 + 驾驶员确认）
- `getGlobalWorldbookNames()` → 全局启用列表（当前为空 []！）；`rebindGlobalWorldbooks(names[])` = 设置全局启用（内部就是 $('#world_info') DOM 操作的官方封装，即驾驶员所指"那个 DOM 操作"）
- `getWorldbookNames()` 同步返回酒馆全部书文件名（存在性判据）
- `getCharWorldbookNames('current')` → 绑定记录（仅作资产归属，不作启用判据）

### 失败回退
`navigator.clipboard` 权限问题 → 降级为 textarea 手动全选复制
