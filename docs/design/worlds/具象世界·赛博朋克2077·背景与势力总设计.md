## 〇. 文档职责与定位

### 0.1 这本卷是什么

《具象世界·赛博朋克2077》整本大书由五卷构成：地理空间卷（已冻结）、世界总纲、政治经济社会、巨型企业、帮派与流浪者。**本文档承接后四卷**（背景 + 势力），为它们建立统一的：现在时锚点、双轨叙事、可信度纪律、条目模板与 UID/order 分段。

### 0.3 本卷的四个待破悖论（脑暴靶心，进度标注）

1. **“荒坂悖论”**——玩家 2077 记忆里荒坂是夜之城的天，但 2045 现在时荒坂**刚被核弹逐回日本、在城里没有合法据点**。谁在 2045 填补权力真空？（卷零 BG-D2 定背骨 ✅；卷二 UID 40 荒坂缺席样例已草拟 §5G）
2. **“自由市悖论”**——2045 夜之城是无市长的企业军政管委会紧急状态；2077 才是统一战争后的国际自由市邦。同一座城，两套治权。（卷零 BG-D1/D8 + UID 0/3/4 ✅ 已解）
3. **“帮派记忆错位”**——巫毒帮 2077 是海地裔黑墙 netrunner，2045 却是“冒充者白人毒贩”；The Mox 2076 才成立，2045 根本不存在。（卷三 BG-D34/35 + UID 74 巫毒帮样例已草拟 §5H，待终审）
4. **“货币双源”**——canon 的 eb（欧元）vs 2042 书“禁定汇率、留白”纪律。（卷一 BG-D14 ✅ 已结案）

### 8.4 depth / position 语义与 order 作用域（2026-09-19 驾驶员提示 + 实测）

> 脚本 `.tmp/depth-position-scan.mjs` 扫 22 本 / 872 条实测：

| 字段 | 分布 | 事实 |
| --- | --- | --- |
| position | **0（↑Char 角色定义之前）= 869**；4（@D 按深度）= 3 | 全库几乎只用一种注入点 |
| depth | 4 = 869；1/2 = 3 | 869 条的 `depth=4` 是**惰性默认值** |
| role | null = 869；0 = 3 | — |

**ST 1.18.0 机制（🟡真机敏感，最终以导入实测为准）：**

1. **`position=0` 时 `depth` 字段被 ST 忽略**——所以全库“depth 都是 4”并非有意分层，而是默认值从未参与定位。真正 @Depth 注入的只有 3 条。
2. **order 的主分组键是 `position`**（@Depth 时再加 `depth`+`role`）。**同一注入点内**，order 决定条目拼接先后。
3. 全库 869 条共处**同一个 position=0 注入块**，因此**共享唯一一条 order 序列**——驾驶员“order 是针对同一 depth 的划分”的直觉在本库成立；更精确表述为“**order 针对同一 position（及 @Depth 的 depth+role）分组**”。
4. **budget 触顶淘汰**近似按 order 跨激活条目全局比较（🟡待真机确认全局 vs 分组作用域）。

**对本卷的三条落地纪律：**

- 本卷背景+势力条目**沿用项目惯例 `position=0`**，与地理卷、现有 20 本一致；则 order 分带（§8.3）是本卷唯一的排序/存活旋钮，必须认真分带，不可因“看似都在同带”而松懈。
- 不要用 depth“制造独立 order 空间”——当前无 @Depth 惯例，且 depth 与世界排他（BG-D4）正交，救不了同库冲突。
- 新书写盘时 `position/depth/role` 显式钉死为 `0/4/null`（与家族书 2042 一致），避免继承全局漂移（承优化技巧 技巧 9 的“显式钉死”精神）。
