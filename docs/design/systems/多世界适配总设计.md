## B. Core Spine 冻结稿

### B1. 五层结构

| 层 | 内容 | 归属 |
|---|---|---|
| **核心层（永恒常量）** | schema 世界无关域、catalog 数据、MVU tag 协议与合并语义、首台机娘法则、机娘平衡总纲、藏字诀、暴露数值轴 0–10、通用书本征能力（雷达截面/红外/声学/装甲/航程/火力/可伪装性评级）、启动器框架、E7 编写律 | 跨世界不变 |
| **世界适配层** | world manifest（机器配置）+ 世界适配书（叙事六章）+ 伪装辞典 + 效力矩阵 + 观察者表 + 合法货币名单 + 历法 + 本地引进轨 | 每世界一套 |
| **阵营层** | 武备·阵营书、特色科技·阵营书（现盟军；苏/尤 order 带已预留 71000/72000 段） | 跨世界、按参战挂载 |
| **剧情层** | 剧情书/基地书（北坡纪事、采药营地 = 修真×北坡战役） | 属"某世界某战役" |
| **数据层 hidden** | worldAffinity 标记、隐藏科技、登月 flag、月面发现物 | 机器可见、叙事禁泄（R7） |

### B2. 引用纪律（禁止反向污染）

1. 世界适配书/剧情书**可**点名核心层与阵营层名词（型号名、研究名、法则名）；
2. 核心层与阵营层**禁止**出现任何世界专属实体（修士/灵觉/天网/netrunner…）——A4 豁免白名单除外；
3. manifest 机器配置**单向**供给前端；前端永不解析叙事世界书正文（双源一致铁律延伸）；
4. 适配书对型号只写"该世界如何看待/该能力在此世界表现如何"，**不得复写本征参数**（雷达截面等留通用书，防双真源漂移）。

## C. 开局选世界流程（含异常分支）

### C1. 主流程（扩展现有启动器 $boot 状态机）

1. 新建会话 → #0 楼归零态（现有机制）；
2. 启动器新增 **Step0·世界选择**（数据源 = worlds manifest；首版两卡片：修真正史 / 赛博朋克2042）；
3. `choices.worldId` 入向导状态 → Step4 体检按所选世界书单判定（替换 `Step4Launch.vue` L129 `WORLD_ID='xiuzhen'` 硬编码）；
4. 发射管道（`buildStatData` + `bindWorldBooks` 现有工序位）：
   - 写入 `meta.world_id`；
   - 按 `manifest.currencies` 初始化 wallet（各货币键 = 0 或表单值）；
   - `bindWorldBooks` 实装排他启停：`rebind(当前全局 − 全部已知世界组书 ∪ 选中世界组书)`（停其他世界、启本世界，保留用户自有书）；
   - `markBoot` 快照含 worldId；
   - 按世界 `opening_profile` 生成开场白。

### C2. 异常分支矩阵

| 场景 | 处理 |
|---|---|
| 重复初始化（重载/读档/切卡） | `$boot.confirmed` 现有防线覆盖，不重跑 |
| 取消选择 | 现有重置回滚机制覆盖 |
| 旧存档迁移 | importSave 检 `schema_version<2` → 迁移器补 `world_id='xiuzhen'`（旧档必为修真）+ wallet 键改造（见 D） |

| world_id 非法（不在 manifest 注册表） | **不静默改写**，体检红灯，停在启动器等用户裁定 |
| 读档恢复 | stat_data 随楼传承天然恢复；世界书启用为全局态，开局体检按当前档 world_id 重查并一键修复 |
| 中途切世界 | **第一版锁死（D27）**：① UI——世界选择仅存在于启动器 Step0，`$boot.confirmed` 后不可达；② 协议——条目92 明文 world_id 为系统只读字段；③ 解析器——L2 对 LLM 写入 world_id 一律忽略并记🟡。开发/测试仅靠 `$boot 重置`重开局，不提供在档切换 |
| 多开会话串状态 | **本次新发现**：全局启用列表为 **ST 应用级**而非聊天级——文档明示"一酒馆实例同一时刻一个活跃世界"，靠每档开局体检检测失配并一键修复；列 P7 真机验证项 |

## E. 世界适配数据契约（manifest · D26）

**载体：TypeScript**，新建 `src/红警指挥系统/worlds.ts`；现 `worldbookManifest.ts` 书单并入并由启动器 re-export 兼容。机器配置与叙事正文彻底分离。

```ts
interface WorldManifest {
  world_id: string;                        // 唯一键：'xiuzhen' | 'cyber2042' | …
  display_name: string;                    // Step0 UI
  calendar: { label: string; sample: string };            // 历法格式提示
  currencies: string[];                    // wallet 白名单（L2 校验 + UI 排序）
  worldbook_group: { name: string; required: boolean }[]; // 启用书单（通用组+阵营组+适配书+剧情书）
  technology_baseline: string;             // 一句话水位（UI；叙事真源在适配书②章）
  observers: string[];                     // 观察者简表（开场白/UI；叙事真源在③章）
  world_affinities: Record<string, '有效' | '降效' | '无效'>;  // 位面支线科技在该世界的效力
  local_import_tracks: string[];           // 本地引进轨名（后续接 catalog）
  opening_profile: { location: string; presetHint: string };
}
```

**读取方与时机**：Step0（display_name/currencies 展示）· 发射管道（worldbook_group/currencies/opening_profile）· parsePipeline L2（currencies 校验，按 `stat_data.world_id` 取）· 系统 tab 体检（worldbook_group）。
**校验**（新增 vitest）：每世界 `currencies≥1`、书单非空、`world_affinities` 键在 catalog 权威名单内、world_id 全局唯一。
