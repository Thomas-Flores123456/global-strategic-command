## 一、编写规范（撰写前必读）

以下全部为已拍板的准绳。动笔之前，请从头到尾把这一节读完。

### 1.1 五段式模板（D16）

每位机娘按此五段撰写，不多不少：

1. **标头**：`名字——型号首台（造价）`。名字在正式命名前以占位符代替。
2. **形态机制**（可选）：如果她有特殊的人形/分体/切换机制，在这里写清楚——比如白凌的三七分体、M1E3 的混动双心脏。没有的可以跳过。
3. **能力 3–5 条**：**首条标注"（核心）"**，每条必须带**位面内度量衡量化参数**。能力不是越多越好，三到五条足够勾勒一个人的轮廓。
4. **主副武器与武装分档**：先列出**人形态主/副武器 + 载具态主战武器**，再按三档标注暴露等级——
   - 🟢 **可公开**（伪装层）：日常可见，不暴露身份。
   - 🟡 **严禁公开**（隐蔽层）：使用即造成中高级暴露。
   - 🔴 **终极底牌**（底牌层）：使用等于最高级暴露。
   > **武器观**：越大型的平台，人形态随身武器越弱。预警机、航母、导弹发射车——她们人形态近乎非武装，因为真正的"武器"是那座庞然载具，或者她掌握的信息与编队本身。反过来，小型平台的机娘人形战力反而更强。手里有刀的，往往不是最可怕的那个。
5. **结构性短板 ≥2 条**：必须是**非装饰性**的，能在战术层面构成真实约束——维护负担、续航瓶颈、对外依赖、性格软肋。花瓶短板不算数。

> 贯穿全书的精髓只有一句话：**每个技能自带暴露代价——越强越难藏。** 技能系统与"藏字诀"世界观是咬死在一起的。

### 1.2 位面内度量衡（量化词表，禁用米/秒/公里）

| 维度 | 用词 |
|---|---|
| 距离 | 步（≈1步）/ 里 / 臂（≈手臂长，近距） |
| 时间 | 息（≈1呼吸）/ 拍 / 炷香（≈半刻）/ 盏茶 / 时辰 |
| 精度 | 正负 X 拍 / X 步 |
| 切换耗时 | 人形↔载具"切换约 X 息"——**随体量增大而增长**（小车约三十息 / 巨舰巨机约五十至六十息） |

### 1.3 平衡性总纲（D21+D22，已入档案书 uid0 通则）

这是撰写时的**铁律**，目的是防止一件最不该发生的事——老角色因为新角色的到来而黯然退场。

- **同类型机娘个体战力基本一致**。差异只允许出现在两处——
  1. **专属技能特长**：独门技能，以及全局排名类特长（例如乔念"射击第一"、顾棠"精度第二"）。
  2. **类型方向差（域特性）**：
     - 人员类：**最易伪装**。人形即本体，社会融入最高，走在人群里最不惹眼。
     - 陆军类：**装甲厚实**。人形态挨得起揍，防护与近战是看家本领。
     - 空军类：**可以飞**。人形态具备飞行能力——这三个字在修真位面意味着什么，不必多说。
     - 海军类：**海上跑**。人形态水面立行，同样不是这个世界里平凡的事。
- **层次分离**：总纲管的是**角色层**（人形态与分体的个体能力）。载具本体的性能差异归**武备书数据层**处理——M1E3 的炮当然比灰熊的新，但那是武器的事，不是人的事。角色不因载具换代而贬值。

### 1.4 域能力暴露约束（D24）

空军的"飞行"和海军的"水面立行"属于**超凡表现**：

- 一律归🟡隐蔽层 / 🔴底牌层管辖。**公开使用 = 高级别暴露**（与乔念公开使用机枪档的暴露等级相当）。
- **可自由使用的场合**：地下基地内 / 远海无目击区域 / 确认无观察者的环境。
- 设置这条约束，是为了防止"舰娘水上漂"在修真位面变成当众显圣。那画面虽然好看，但不能要。

### 1.5 T2 世代注记（D21）

T2 与 T1 之间的区别，**不是战力高低，而是短板结构的不同**。这一点至关重要：

- T2 机娘**技能更强，但也更依赖体系**：数据链、电力、后勤——一旦断供，降级幅度远大于 T1。
- T1 老兵"单兵自持"，断链环境下反而**更可靠**——这是给老角色保留的不可替代的舞台。新锐需要网络才能满血运转，老将断了线照样能打。
- 与 1.3 总纲并存，不矛盾。

## 三、技能设计（按线分章）

> 本节先誊入**八旗舰样板**（D20 已过审），作为全文的标杆和参照。其余简档按线分批补入，每批一条线。
>
> **简档字段格式**（每位一块，比世界书简表略详）：名字（占位）—型号 ｜ **核心技能**（+量化+暴露代价） ｜ **⚔ 主武器 / 副武器 / 底牌**（人形随身+载具态主战） ｜ **结构短板**×1 ｜ **性格向**一句。

### 3.A 陆军线

#### ★ M1E3 下代主战坦克（沉稳小妹）

她的胸腔里跳着两颗心脏——一颗燃气轮机的怒吼，一颗电池组的低语。混动双心脏是 M1E3 最独特的拟人化印记。

- **能力**
  - （核心）**静默电行**〔参考名"屏息"〕：切换至纯电行进时，热信号与声纹骤降至民用水平。持续约一炷香；常规听觉三十步外不可辨，热感知视同耕牛体温。五十八吨的钢铁，忽然像雾一样安静。
  - 无人炮塔遥控：本体离车后可在百步范围内遥操火力，人与炮塔不必绑在一起。
  - 主动防御截击：对来袭弹药与法器投掷物实施拦截，但每轮窗口有限——不是万能盾。
- **⚔ 主副武器**：人形态持重型战锤+塔盾（陆军近战向，伪装层可充仪仗队器具）；副=隐蔽层大口径手枪；🔴底牌=离车百步遥控载具态 120mm 滑膛炮。
- **暴露分档**：🟢 静默电行（伏击与渗透的无声利器） / 🟡 无人炮塔遥操 / 🔴 主动防御开火=金属风暴——等同当众开炮，方圆数里尽知。
- **短板**：双心脏的维护复杂度高居全陆军之冠，任何一颗出问题都是大事。五十八吨的车身过桥过田必留深辙压痕——走过的路，藏不住。

#### ★ 暗鹰 LRHW 高超声速打击（寡言终结者）

平时不开口。因为她一开口，就是终结。

- **能力**
  - （核心）**高超声速打击**〔参考名"最后通牒"〕：三千公里级射程，五马赫以上，从发射到命中以盏茶计。天下最远的一拳。
  - 发射前置仪式：起竖、瞄准、多重授权确认——流程本身即技能，每一步都不能省。
- **⚔ 主副武器**：人形态近乎非武装——她真正的武器是那枚导弹本身，别的都是陪衬；副=隐蔽层一柄消音手枪聊作自卫；🔴底牌=载具态高超声速打击（位面级事件）。
- **暴露分档**：🔴 发射即位面级事件——尾焰冲天、雷鸣彻地，车位即刻暴露，打了就必须跑。
- **短板**：再装填周期以日计，打完之后她就是个空壳；无自卫能力；一发天价，容不得浪费。性格逻辑是"开口即终结，所以平时不开口"——寡言不是冷漠，是尊重自己手里那东西的分量。

#### ★ 幻影坦克（拟态大师·壁花）

你也许看过她，但你不知道那是她。

- **能力**
  - （核心）**完美拟态**〔参考名"林中人"〕：静止约十息后与周围环境同化，光学与灵觉双频段生效。修士用神识扫过，感知到的只是"一棵金属质地的树"。拟态库需要她亲自到实地扫描采集——每到一个新环境，都得先花时间"学"那里长什么样。
  - 拟态库管理：多环境模板的存储与切换，是她日积月累的功课。
- **⚔ 主副武器**：人形态消音手枪+可藏软剑（潜行向，伪装层里那柄不露痕迹的软剑）；🔴底牌=拟态态载具主炮贴脸突袭——"树"突然开炮的那一刻，是战场上最惊悚的画面之一。
- **暴露分档**：🟡 拟态态本身 / 🔴 移动即破功，开火瞬间现形；而且"金属树"这个感知痕迹对已起疑的人来说，反而是一条线索。
- **短板**：拟态优先牺牲了装甲厚度——是陆军线里出了名的薄皮。性格上存在感稀薄，她到底是乐在其中，还是其实渴望被人看见？这个反差留着，比写死更好。

#### ——陆军线简档（18 位）——

> 同级战力按平衡总纲拉平，差异只在专长方向与暴露代价。以下每一位都有自己的活法。

**〔名字待定〕· 灰熊坦克**（T1 基石 · 战车工厂出厂无需研究）

她是所有人最先认识的那辆坦克——没有花哨的技术，只有"打不死"三个字。

- 核心：**皮实耐战**〔"老黄牛"〕——纳米躯壳能在战场上现场愈合中小创伤，连战不下火线。可靠性全陆军之最，代价小、暴露低。
- ⚔ 人形态重刃+塔盾（近战向）／副=隐蔽层手枪／🔴底牌=载具态 120mm 滑膛炮。
- 短板+性格：对 T2 目标存在火控与弹种代差，需要体系来补位。老兵大姐，稳、糙、护短——后辈出事了她第一个冲上去。

**〔名字待定〕· 布拉德利 IFV**（T1 · 步兵战车）

她的本事不是自己有多能打，而是让车里的四个人都活着下车、活着回来。

- 核心：**载员协同**〔"老母鸡"〕——车内至多四步兵的战术调度与同步下车，搭载步兵存活率显著提升。协同链路小功率，暴露低。
- ⚔ 人形态卡宾枪+格斗匕（中距）／副=车载 25mm+TOW 遥操／🔴底牌=载具态反装甲齐射。
- 短板+性格：本体装甲只扛得住轻武器，硬碰主战坦克必败。稳重前辈，XM30 的亲姐姐——嘴上念叨着"小心点"，手已经替你挡了。

**〔名字待定〕· CFV 装甲侦察车**（T1 · M3 侦察型）

看得最远的那个人，通常也是最沉默的那个。

- 核心：**多模态侦察**〔"千里眼"〕——光/红外/声/灵气四模态阵列，前沿标定为后方火力指路。被动接收暴露极低，但主动灵气探照可能被察觉。
- ⚔ 人形态短弩+手枪（轻装斥候）／副=25mm 自卫／🔴底牌=呼叫标定火力——自己不打，指引别人打。
- 短板+性格：薄皮高速，绝不硬碰。眼尖机敏，话少，先看后动。

**〔名字待定〕· M1A2 SEP 主战坦克**（T1 装甲之最 · M1E3 量产后转梯次不退役）

陆军线正面最硬的一面墙。M1E3 叫她一声"前辈"，她回一句"接好了"。

- 核心：**重甲突破**〔"铁砧"〕——正面复合装甲能扛住 T1 一切常规穿甲弹，猎-歼双火控同时锁多目标。主动防御一开即金属风暴，等同当众开炮。
- ⚔ 人形态巨剑+重盾（突破向）／副=隐蔽层大口径手枪／🔴底牌=载具态 120mm+顶置遥控武器站。
- 短板+性格：六十三吨——过桥过田留的辙痕是全陆军最深的，哪座桥扛得住她是个永恒的难题。沉稳老将，把 M1E3 当接班小妹带着。

**〔名字待定〕· 帕拉丁自行火炮**（T1 · 远程间接火力核心）

她的枪口朝天，弹着点在十里外。开炮是她的工作，跑路也是。
