## 1. 协议动机与通道定位

在剧情推进中，LLM 经常动态构思新科技、配套建筑、特种载具、战术装备或特殊人员。现有通道存在以下边界：

| 标签 | 职能 | 局限 |
| :--- | :--- | :--- |
| `<图鉴>` | 摘要索引（1~2 句） | 仅在变量树 codex 留一行，缺乏完整设定长文 |
| `<机娘档案>` | 机娘专属完整八段档案 | 仅限机娘角色，通用装备/建筑/科技无法使用 |
| `<数据更新>` | 既有条目 `<数据>` 块补丁 | 仅限既有条目，无法为新造物创建条目 |
| **`<扩展档案>`（本案）** | **新实体完整世界书设定条目** | **LLM 动态创造新科技/建筑/载具/人员/装备的标准入档通道** |

`<扩展档案>` 产物落入当前聊天档案书，避免跨聊天数据污染；后续支持在管理页一键「提升」为独立世界书私产。

## 2. 何时报出 `<扩展档案>`（触发时机）

### 2.1 触发场景（DO）
- 指挥官完成某项重大自主科技研发（如“等离子脉冲炮”、“隐形力场发生器”）；
- 基地新建了剧本独创的特殊建筑（如“磁暴充能基座”、“纳米修复塔”）；
- 兵工厂试制下线了首台全新改型载具（如“自杀式无人履带车”、“重装空艇改型”）；
- 剧情中登场了重要非机娘专属 NPC 或特殊战术编制（如“雷达站首席技术官”、“幽灵侦察小队”）；
- 研制出新型战术装备或单兵特种武器。

### 2.2 严禁报出场景（DON'T）
- ❌ **机娘角色诞生**：一律走 `<机娘档案>`，严禁走 `<扩展档案>`；
- ❌ **既有设定条目的数值改造/工况变更**：一律走 `<数据更新>`，严禁走 `<扩展档案>` 重复建档；
- ❌ **阵营势力信息**：阵营信息走 `<战况>` 中的 `势力` 字段，不进本通道；
- ❌ **常规战况数据流水**：资金、电力、队列进度走 `<战况>` 标签。

## 3. 标签体例与字段约束（草案）

### 3.1 字段规范

```yaml
<扩展档案>
名称: string                      # [必填] 实体全名，如“等离子脉冲炮”
类别: 科技 | 建筑 | 载具 | 人员 | 装备 # [必填] 五大枚举之一（阵营/其他不进本通道）
简介: string                      # [选填] 1~2 句核心摘要（自动派生 codex 索引）
参数:                             # [选填] 关键规格键值对
  造价: string
  耗电: string
  工期: string
  前置: string
设定: |                           # [必填] 完整技术散文与战术背景，世界书条目正文主体
  详细交代其运作机制、物理特征、战术用途、优缺点与部署纪律。
  【纪律要求】：散文详写，严禁过度标签化或敷衍成一两句话。
关键词: string | list              # [选填] 激活词列表（精确匹配触发词）
数据:                             # [选填] 结构化属性块（对齐标准数据块规范）
  type: string
  tier: number
  power: number
</扩展档案>
```

### 3.2 报文示例

```yaml
<扩展档案>
名称: 聚变增压线圈
类别: 建筑
简介: 针对大型特斯拉线圈的超高压外挂储能升级单元。
参数:
  造价: 1800
  耗电: 60
  前置: 战斗实验室, 特斯拉核心
设定: |
  聚变增压线圈是北坡前哨基地工程团队在遭遇重装甲集群压迫后研制的就地升级方案。
  该设施由四组液氮冷却的超导储能环组成，平时自电网吸纳冗余电荷，在遭遇高威胁目标时，
  可瞬时向连接的特斯拉防御阵列释放三倍峰值电压，对重型装甲造成穿透性电弧击穿。
  短板在于持续放电后存在 45 秒的热过载冷却窗口，此期间防御塔处于降频待机状态。
关键词: 增压线圈, 聚变线圈, 特斯拉增压
数据:
  schema_version: 1
  type: building
  tier: 2
  power: 60
</扩展档案>
```
