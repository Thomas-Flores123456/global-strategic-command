## 〇. 立项背景与红线继承

### 0.1 起因（2026-09-19 脑暴链）

驾驶员在盟军超武（超时空传送仪/天气控制仪）定价对账中发现两个问题：

1. **超武塌陷**：原版 5,000 credits 的超武比一艘伯克级驱逐舰（8,000）还便宜，量级失衡；
2. **经济根因**：实测剧情采用"1 系统资金 = 1 美元"外汇兑换，导致经济系统崩坏。

顺藤摸瓜，本质问题是：**全库 credits 缺乏统一的一般等价物哲学**，也缺乏"各类矿石/金属/废料/异界高价值物 → credits"的系统化转化规则。

### 0.2 根因诊断：credits 的唯一合法产生阀门

> **credits 只能由"实物进精炼厂/回收厂重构"产生，不能由外部货币兑换而来。**

"1 系统资金 = 1 美元"之所以崩，是因为它把 credits 当成了**外汇兑换标的**（拿美元换 credits），这违背了 credits 的本质——它是指挥部纳米经济的**内部配额记账单位**，不是流通货币。

## 1. 第一章 · 一般等价物哲学

### 1.1 credits 的本质定义

> **credits（系统资金）＝ 指挥部纳米经济网络的内部配额记账单位。**

它衡量的不是"多少钱"，而是"指挥部能调度多少纳米重构产能"。它：

- **只增不换**：只能由实物进炉重构产生，不能由外部货币兑换获得；
- **对内统一**：跨世界通用，是指挥部内部的唯一硬通尺度；
- **对外隔离**：与各世界 `wallet`（本地货币钱袋）严格双轨，不自动兑换。

### 1.2 精炼基准当量（BME）——唯一的物理原点

> **锚 0 · BME**：标准基础金属矿**满载一车 ≈ 500 credits**（沿用红警原生结算 + 现行 catalog 采矿车基线）。

这是全库唯一的"物理 → credits"标尺原点。所有其它进料的估值，都是**相对这一车标准矿**的系数换算。定这一个点，其余全部由模型推导，避免多锚打架。

### 1.3 为什么不用黄金质量做总锚（反例存档）

Gemini 曾提议"1 credits = 1 克/盎司黄金"。此路被否，存档反例以防复活：

1. **黄金流通盘撑不住**：人类史总产金约 21 万吨、央行储备约 3.6 万吨、年产约 3,000 吨。盎司锚下一辆坦克吃 25 kg 金、一座超武吃近 1 吨金，一场战役抽干一个国库，世界观崩塌。
2. **标尺锚错对象**：按"黄金只是痕量催化剂"的 flavor，超武真实成本在**纳米工料吨位＋工期＋算力＋兆瓦耗电＋超导阵列**上，与那点金无关。用金质量定价会系统性严重低估——克金锚下"能撕裂时空的巨构比一枚战斧巡航导弹（约 $1.5–2M）还便宜"。
3. **撞双轨红线**：钉死 credits↔黄金汇率，正是 §0.3 两本适配书明令禁止的。

### 1.4 定价锚该锚什么

> **锚定"内部生产物理 + 相对阶梯"，而非"外部货币质量"。**

一件装备/建筑值多少 credits，取决于它消耗多少纳米工料、多长工期、多少算力与耗电，以及它在既有装备阶梯（伯克 8k / 空间站 20k / 核航母 35k）中的相对位置——**不取决于任何外币或贵金属的市场价**。

## 2. 第二章 · 估值三轴模型

任何一份进料转化为多少 credits，由三根正交轴共同决定：

> **最终 credits ＝ 品位基数（轴一）× 初始加工态修正（轴二）× 加工深度系数（轴三）＋ 伴生副产物回收增益**

### 2.1 轴一 · 品位基数（Grade Base）

以 BME（标准矿满载 = 500 credits）为原点，给每种进料一个**满载基数倍率**：

| 倍率 | 含义 | 典型 |
| :--: | :--- | :--- |
| 0.3–0.5x | 低值垫底料 | 废钢、建筑废金属 |
| 1.0x | 基准 | 标准铁/金属矿 |
| 1.2–2.5x | 中高值 | 铜矿砂、稀土矿 |
| 2.0–3.0x+ | 富贵金属/富回收 | 金银原矿、企业级/军工级电路板 |

#### 2.1.1 来源工况等级子轴（Q3 引出 · 赛博废料专用）

**驾驶员冶金学修正（2026-09-19）**：电子/机电废料的贵金属浓度**主要由原设备的工况等级决定**，而非笼统"是电子废料就值钱"。工况越极限，越必须用厚镀金防氧化、铂钯钽电容、抗辐射稀有金属（钽铌镓锗铪，本身即战略物资）——这些正是提纯时榨得出的高值副产。故在轴一品位基数下增设**来源工况等级**修正档：

| 来源等级 | 工况特征 | 贵金属/稀有金属浓度 | 品位基数 |
| :--- | :--- | :--- | :-: |
| **消费级** | 民用常温常压、成本导向 | 低（聚合物骨架＋普通钛＋消费芯片） | 0.5–1.0x |
| **企业级** | 数据中心/电信 7×24 高可靠 | 中高（镀金连接器＋高层数板） | 1.2–1.3x |
| **军工/航天级** | 极限工况（高辐射/深空/战场） | **最高**（厚镀金＋铂钯钽＋抗辐射稀有金属） | **1.3–1.6x** |

> **铁律修正**：**民用义体"含金量"严重不足**（大量聚合物＋普通钛合金＋消费级伺服，贵金属稀薄），不是天花板；真正的浓缩富矿是**军工/航天级极限工况电路板**。来源等级子轴只在赛博等"制造废料为主"的世界启用，天然矿仍按品位基数正表。

### 2.2 轴二 · 初始加工态（Initial Refinement State）

**这是本轮驾驶员纠正引出的关键轴**——同一种金属，进料时处于什么加工阶段，决定了它"还剩多少加工空间"给你赚：

| 加工态 | 定义 | 加工空间 | 估值特征 |
| :--- | :--- | :--- | :--- |
| **原矿（raw ore）** | 未经任何选冶、直接从矿床开采的天然矿石，大部分是脉石 | **最大** | L0 低（金属锁在脉石里流失）、L3 高（提纯＋伴生释放） |
| **废料（scrap）** | 报废电子/金属制品，含金属但混杂 | 大 | L0 低、L3 高（回收提纯） |
| **半成品** | 已初选精矿/合金坯 | 中 | L0/L3 差距收窄 |
| **成品锭（ingot）** | 已提纯金属/宝石成品 | **无** | L0 = L3 足值（对照组） |

> **铁律**：原矿 ≠ 金属锭。金银**原矿**粗投（L0）时因脉石锁死金属而值低，全精（L3）时因提纯＋伴生而值高；金银**锭**已是纯成品，L0=L3 足值、无加工空间。

### 2.3 轴三 · 加工深度（Processing Depth）· **分档梯**（Q1 已确认 2026-09-19）

同一堆进料值多少，还取决于你的产线建到了第几段（严格对齐 `通用·工业基础` uid18 废弃电子回收四段线）。四段工序与瓶颈固定如下：

| 深度档 | 工序 | 建筑门槛 | 瓶颈（canon） |
| :--: | :--- | :--- | :--- |
| **L0 粗投** | 人工/机械粗筛 → 直接进精炼厂 | 矿石精炼厂 | 无（管饱） |
| **L1 半精** | +一段粗拆分选（磁选/涡电流） | +回收厂一段（纯机械·便宜·可扩吞吐） | 进料密度 |
| **L2 精拆** | +二段纳米精拆（回收完整元器件复用） | +二段 | **算力**（占核心约一成带宽） |
| **L3 全精** | +三段湿法/火法贵金属提纯 | +三段 | **废液处理**（酸液/暴露源） |

**关键裁决（Q1）**：加工深度系数**不是全料通用的单一梯**——它由轴二"加工空间"决定档位。反算 §6 三张世界表证实：金属锭 L3/L0＝×1.0、普通铁矿＝×1.3、混杂废料＝×1.7、富集料＝×2.0–2.5、复杂高值＝×3.0。故确立**五档加工空间梯**（每档一套 L0→L3 系数，均以 L0＝×1.0 为该料自身原点）：

| 加工空间档 | 代表进料 | L0 | L1 | L2 | L3 | 复现验证 |
| :--- | :--- | :-: | :-: | :-: | :-: | :--- |
| **足值成品** | 金银锭 / 成品宝石 | 1.0 | 1.0 | 1.0 | **1.0** | 锭 1000→1000 ✓ |
| **浅（普通新矿）** | 铁矿 / 铜矿砂 | 1.0 | 1.1 | 1.2 | **1.3** | 铁矿 500→650 ✓ |
| **混杂废料** | 废钢 / 废铁 | 1.0 | 1.25 | 1.5 | **1.7** | 废铁 200→340 ✓ |
| **中（富集料）** | 稀土 / 混合电子废料 | 1.0 | 1.3 | 1.8 | **2.0–2.5** | 稀土×2.0 / 电废×2.5 ✓ |
| **深（复杂高值）** | PCB / 电池 / 义体废件 / 贵金属**原矿** | 1.0 | 1.4 | 2.2 | **3.0** | PCB 500→1500 ✓ |

> **深档 L3 保持 ×3.0，不上抬到 ×3.5**（Q1 确认）：贵金属**原矿**的诱人度靠伴生增益（§2.4）叠到有效 ×3.45～4.2，而非抬高基础系数，以免过冲 §6 表内 1500 的目标值、砸掉自己的配平表。
>
> 设计要点：前期只有精炼厂 → 只能 L0 粗投赚第一桶金；中期建全回收厂 → 同一车料按其档位翻到 L3（普通矿仅 ×1.3、富矿/废料 ×2.0–3.0），但受**算力＋废液双瓶颈**，逼玩家权衡"建造带宽 vs 赚钱带宽"。L2 回收完整元器件可直接复用（赛博义体废件甚至无需回炉），间接降低装备成本约一成。
>
> **LLM 落料指引**：新进料先按轴二"还剩多少加工空间"对号入五档之一，再取该档 L0→L3 系数；无法判断加工空间时，走 §7 方案③稀有度四档兜底分档。

### 2.4 伴生副产物回收增益（Associated Byproduct）· **仅原矿·三档·仅 L3**（Q2 已确认 2026-09-19）

**这是本轮驾驶员的核心冶金学贡献**——建起三段提纯线后，薅的不只是主金属：

- 斑岩铜矿伴生金、银、钼、硒；
- 铅锌矿伴生镉、铟、锗、银；
- 铂族本就是铂/钯/铑/镍/铜共生；
- 金矿伴生银。

因此天然原矿 L3 全精的真实收益 = 主金属提纯值 **＋伴生贵/稀金属额外产出**，这让 L3 的吸引力再上一档，也是"为什么值得建全线"的世界观动力。

**关键裁决（Q2）· 伴生增益四条边界**：

| 裁点 | 确认结论 | 理由 |
| :--- | :--- | :--- |
| **谁吃伴生** | **仅天然多金属共生原矿**（斑岩铜伴金银钼硒、铅锌伴镉铟锗银、铂族共生、金矿伴银） | 只有地质共生才有"薅副产"；这是伴生增益的物理前提 |
| **谁不吃** | **制造废料（PCB / 电池 / 义体废件）不吃伴生** | PCB「每吨 200~400 克金」是**主回收目标**、义体价值是**完整元器件复用**，均已烘进深档 ×3.0；再叠伴生＝双计 |
| **三档幅度** | 单一伴生（金伴银）**+15%** ／ 中等共生（铜系、铅锌）**+25%** ／ 富多金属（斑岩铜、铂族）**+40%** | 把原「+15%~+40%」模糊区间钉成三档可判值 |
| **结算层级** | **仅在 L3 结算**（L1/L2 化学上拿不到痕量伴生） | 三段湿法/火法才释放伴生贵金属 |
| **落盘方式** | **只落 credits 合数，伴生金属不另入 `minerals` 库** | 防双计，守 §8.1「只落 credits」红线 |

> **有效倍率自检**：贵金属**原矿** L3 有效 = 深档 ×3.0 ×(1.15~1.40) = **×3.45～×4.2** → 通用金银原矿 350→约 1470（≈ §6 表内「1500+」）✓。
> **制造废料补偿另计**：消费级 PCB/义体不吃伴生，但 L2「回收完整元器件复用」间接降本约一成（见 §2.3），二者是**不同经济维度**，互不重叠。
> **挂账已清（Q3 处理完毕）**：`修真` 金银原矿已由 300→1600 归一为 **350→1500**（§6.2），落回模型上限内。

## 3. 第三章 · 矿物金属分类学（对齐 schema 六柱）

严格对齐 `CTRL-RES-SCHEMA-01` 已落地的 `EconomyResources` 六柱，估值进料按柱归类，不新造平行分类：

| 柱 | 预置小类（缺省 null） | 本设计估值角色 |
| :--- | :--- | :--- |

### 4.2 转化链拓扑

```text
采矿车（原矿·minerals）─┐
                        ├─→ 矿石精炼厂 ─[L0 粗投]→ credits（稳定基载）
拾荒/回收网络（废料）───┘        ↑
```

## 7. 第七章 · 定价哲学备选与跨世界锚定语协同规范（Q5 已确认 2026-09-19）

除本文档主推的三轴矩阵，另存三个哲学。**它们不是四条平行独立的定价路，而是同一套模型的四种调用镜头**，按下述唯一优先级链协同：

| 方案 | 哲学 | 优势 | 短板 | 定位 |
| :--- | :--- | :--- | :--- | :--- |
| **① 三轴矩阵**（品位×加工态×深度）★主锚 | 内部生产物理 | 最贴 canon、成长曲线天然浮现 | 需三参数 | **数值主锚（唯一权威落盘值）** |
| ② 满载倍率锚 | 一切只说"相对标准矿几车" | 最抽象、LLM 最好用、天然不撞汇率红线 | 缺物理手感 | **跨世界口头换算通用语** |
| ③ 稀有度四档锚（废料/常规/贵稀/能量结晶） | 分档带宽 | 扩展性最强，新矿秒对号 | 颗粒粗 | **LLM 塞新矿兜底分档** |
| ④ 风险×稀缺锚 | 稀缺/可及性叙事 | 剧情张力最强，"先过怪""巨头不做的金山" | 易越界改价 | **纯剧情 flavor（不进落盘公式）** |

### 7.1 【Q5-a】四锚唯一决策链 ＋「④不落盘」铁律

> LLM 或落地子任务给任一新进料估价时，**必须按此唯一顺序决策**，不得各锚各查、给出打架的价：

```text
新进料估价 · 唯一决策链
  1. 能精确对号三轴？（品位基数 × 初始加工态 × 五档深度）
     └ 能 → 用①三轴出数 = 权威落盘值（进 <数据> 块的就是它）
  2. 对不上具体档，但知稀有度？
     └ 用③稀有度四档兜底给区间（见 §7.2）
  3. 只需口头比大小？
     └ 用②满载倍率过渡表达（"约 X 车标准矿"）
  4. 剧情要张力？
     └ 用④风险×稀缺 只做叙事润色，绝不改①的落盘数字
```

> 🔴 **「④不落盘」铁律**：④风险×稀缺因子**只染剧情叙事、绝不进 credits 落盘值**。否则"高危区捡的料"会凭空涨价，破坏 §0.2「credits 只由进炉物理产生」根红线。故 §7 表头原「`credits=基数×稀缺×可及性`」公式已废止——风险不是估值乘数。

### 7.2 【Q5-b】稀有度四档 ↔ 五档梯对齐锚（防串档）

③稀有度四档与 Q1 五档加工空间梯必须钉死映射，LLM 塞新矿先对号稀有度、再落对齐档：

| ③稀有度四档 | → 对齐 Q1 五档梯 | ②满载基准锚（口头语） |
| :--- | :--- | :--- |
| **废料档** | 混杂废料 ×1.7 | ≈0.3–0.5 车标准矿 |
| **常规档** | 浅 ×1.3 / 富集 ×2.0 | ≈1 车标准矿 |
| **贵稀档** | 深档 ×3.0（＋原矿伴生） | ≈2–3 车标准矿 |
| **能量结晶档** | **游离于五档梯外** | **固定值·不翻倍·不吃伴生** |

> **能量结晶档＝跨世界「第六线」**（Q4 灵石线的跨世界推广）：所有世界的**纯能量硬通货**（修真灵石、赛博高能电芯、异界能量体……）统一走这一档——固定转化、不吃加工深度、不吃伴生增益，其价值在**不可替代的能量/前置属性**（如微晶原料），而非 credits 倍率。新世界引入能量物时，一律归此档，不得塞进贵稀档去套 L3×3。

### 7.3 【Q5-c】剧情风险因子的表达边界

④做 flavor 时，钉死"风险只入叙事、不入公式"的表达模板，防止叙事偷偷改落盘值：

| 判定 | 示例 | 结论 |
| :--- | :--- | :--- |
| ✅ **合规**（风险入叙事） | "这批军工电路板在辐射废土里，运出来九死一生……"——credits 仍按三轴 800/2400 | 张力归张力，落盘归三轴 |
| 🔴 **越界**（风险入公式） | "因为太危险，所以这批料值 3000 credits" | 让风险改了落盘数字 = 破 §0.2 红线 |

> **一句话规范**：风险与稀缺是**"值不值得去取"的叙事**，不是**"取到后值多少 credits"的算式**。可及性影响的是玩家愿不愿冒险、以及片区枯竭曲线（§5.2），不是单车估值。

### 7.4 跨世界协同总结

> **主锚组合（Q5 定稿）**：① 三轴＝唯一数值主锚与落盘值 ＋ ③ 稀有度四档＝LLM 新矿兜底分档（按 §7.2 对齐）＋ ② 满载倍率＝跨世界口头换算通用语 ＋ ④ 风险×稀缺＝纯剧情 flavor（§7.1 铁律：不落盘）。四镜头一条链、一个权威值，跨世界统一调用。
