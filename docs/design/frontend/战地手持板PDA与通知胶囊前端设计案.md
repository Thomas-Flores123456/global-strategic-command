## 一、立项动机与物理空间痛点

### 1.1 现状与空间饱和困境
现行红警中控悬浮窗（Floating Console）以 340px 宽度高度紧凑集成了：
1. 顶栏导航（档案、日程、资源、改造、设置、拖拽手柄）；
2. 垂直电网负荷柱（+90 / 10% 动力差额监视）；
3. 基地雷达小地图监视屏（隐蔽中、设施数量、运转状态）；
4. 三大部门快速入口（科技 TECH、工程 ENG、机娘 MECHA）；
5. 六大类建造矩阵网格（60+ 建筑卡片、生产排期与翻页器）。

**痛点**：在已高度饱和的 340px 机柜面板中，强行塞入全新规划的《战区事件流》（多楼层历史通告）与《五阶段资金链状态机》（实体商路、矿脉、采购合同与健康度监视），不仅会导致视觉拥挤崩塌，更会破坏原有“专注基建调度”的心流体验。

### 1.2 战区认知资产的“高时效 vs 低侵入”矛盾
战区推进（每轮 AI 剧情生成）中，LLM 输出的变故（如商路遇袭、发现新势力、前置设施停工）具有极高的**瞬时决策价值**，但玩家在阅读正文时：
* **不能被大弹窗粗暴打断**（破坏小说代入感）；
* **不能被 3 秒即逝的普通 Toast 漏过**（剧情字数多，读完往往错过了提示）；
* **需要一个能够一直静静悬挂、低视觉负担、想看随时点开、看完一键收纳的战术伴生体**。

### 1.3 “同源同胞、绝不造轮子”的技术底线
为了规避多 iframe 架构带来的灾难性后果（内存重复、Pinia Store 割裂、`MESSAGE_SWIPED` 重复监听导致死锁、坐标相互踩踏），战地手持板必须：
1. **同应用实例化**：直接作为中控台 Vue 应用的伴生子组件渲染，共享同一份 `stat_data` 快照；
2. **同样式上下文**：直接继承 `modalHost.ts` 已打通的宿主样式克隆管线与红警 HUD 阵营 CSS 变量（`--ice`、`--line-hot`、`--rac-accent` 等）；
3. **同生命周期**：随中控台一并初始化与销毁，宿主脚本只保留单个控制点。

## 二、双物理形态几何与交互规范

战地手持板在视口中具备两档基础几何形态：**收纳态（战术纽扣）** 与 **展开态（三防手持屏）**。

### 2.1 收纳形态：战术纽扣（Tactical Beacon Button）

```
      ┌─────────┐
      │  ┌───┐  │  ◄── 44px 外壳：哑光聚合物防撞圆角 (border-radius: 50% 或 8px 倒角)
      │  │ ⚡ │  │  ◄── 阵营核心徽章：随阵营变色 (蓝/红/紫)，待机极弱呼吸 (20%~60% opacity)
      │  └───┘  │
      │ ┌─────┐ │
      │ │ 02  │ │  ◄── 未读战报角标 (Badge)：高危亮黄/橙红，无未读时自动隐藏
      └─┴─────┴─┘
```

1. **几何参数**：
   * 尺寸：固定 **44px × 44px**；
   * 边框与阴影：`1px solid var(--line-hi)`，投射柔和的工规微阴影 `0 4px 12px rgba(0,0,0,0.4)`；
   * 背景：`var(--deep-2)`（高透明度磨砂玻璃感 `rgba(15, 24, 32, 0.85)`，配合 `backdrop-filter: blur(8px)`）。
2. **状态灯效与阵营响应**：
   * 盟军（Allies）：微弱冰蓝冷光（`var(--ice)`）；
   * 苏联（Soviet）：战术暗红低辉度光（`var(--rac-accent)`）；
   * 尤里（Yuri）：幽灵冷紫辉光（`var(--tint)`）；
   * 告警跃迁：当有未读的高危事件（`CRITICAL`）滞留时，呼吸灯频次加快并泛微弱琥珀红。
3. **坐标记忆与智能边缘磁吸（Smart Snapping）**：
   * 支持指针拖拽（Pointer Drag），以 `screenX / screenY` 增量计算以保证流畅；
   * **边缘磁吸法则**：拖拽松手时，若距离视口左边缘、右边缘或中控台边缘 $< 60\text{px}$，产生平滑弹簧阻尼磁吸；
   * 存储键：持久化于 `localStorage['tavernweave.pda.state']`，字段包括 `{ x, y, collapsed: true, dockSide: 'left' | 'right' | 'free' }`。
4. **触发动作**：
   * **单击**：切换至展开形态；
   * **拖拽移动**：长按移动坐标，避免误触展开。

1. **几何参数**：
   * 宽度：严格限制为 **320px**；
   * 高度：默认 **440px**（自适应视口高度，最小 320px，最大 560px）；
   * 四角带有三防沉头六角螺栓装饰与斜切工规外沿；
2. **顶栏控制钮（Controls）**：
   * 拖拽抓手（Drag Handle）：按住标题栏任意空白处可自由拖动；
   * `[ — ]` **折叠键**：一键平滑退回到收纳态（战术纽扣）；
   * `[ Pin ]` **固定锁**：锁定当前坐标，禁止意外拖拽位移；
   * `[ ✕ ]` **隐藏键**：彻底隐藏 PDA（可在中控台顶栏快捷按钮中重新呼出）；
3. **四大多维战术页签（3+1 Modular Tabs）**：
   * **`[ 战报 EVENT ]`**：
     * 单楼层事件条目列表，按楼层倒序展示；
     * 每条战报显示：生成时间戳、事件严重度标记（红/黄/绿）、因果描述；
     * 具备“折叠/展开详细损益”功能；
   * **`[ 资金 CASH ]`**：
     * 呈现五阶段资金链状态机总览仪表（`稳定 STABLE` / `充沛 ABUNDANT` / `受损 IMPAIRED` / `紧缩 CRUNCH` / `枯竭 DEPLETED`）；
     * 列表展示各实体链条（商路、矿脉、采购合同）的运转健康度与日净入贡献；
   * **`[ 势力 INTEL ]`**：
     * 显示已遭遇势力名册、态度矩阵（敌对/冷淡/中立/友善/盟友）；
     * **外部世界书落地暂存门（Staging Gate）**：显示大模型在本轮剧情中提及的新增势力或新人物，提供【核准落盘 / 放弃暂存】操作，杜绝幽灵写入；
   * **`[ 任务 OBJ ]`**：
     * 当前作战主线、支线行动与阶段阻碍备忘录。
4. **展开展开动效规范**：
   * 采用机械快门式缩放（Spring Scale 200ms），以收纳纽扣所在坐标为锚点（`transform-origin`）向外弹射展开，绝无迟滞感。

## 三、专项核心：通知胶囊与多条通知解决方案

针对战区事件的高时效性与玩家阅读心流的保护需求，手持板搭载专属的**伴生战术通知胶囊（Tactical Beacon Pill）**。

### 3.1 胶囊形态定义与挂起机制

```
                                【伴生战术挂起通知胶囊】
                               ┌──────────────────────────────────────────────┬───┐
     ┌─────────┐   滑轨弹出     │ 🔴 [资金链受损] 废料商路遇袭 · 净入-150   1/3│ ✕ │
     │  ┌───┐  │ ════════════> └──────────────────────────────────────────────┴───┘
     │  │ ⚡ │  │                 240px 极窄半透明 HUD 条 (高 28px)             关闭
     │  └───┘  │
     └─────────┘
      收纳纽扣
```

1. **弹出时机**：
   * 当手持板处于**收纳态**时，本轮 AI 输出了解析合法的 `<事件>` 报文，或资金链状态机发生了阶段跃迁；
2. **视觉参数**：
   * 高度：极窄 **28px**；
   * 宽度：自适应 **200px ~ 260px**；
   * 紧贴收纳纽扣的外侧（若纽扣靠左则向右滑出，靠右则向左滑出）；
   * 背景为半透明深色微磨砂（`rgba(13, 21, 29, 0.90)`），边框带微弱热线亮边（`border: 1px solid var(--line-hot)`）；
3. **挂起（Persistent）铁律**：
   * **严禁自动定时淡出消失**！
   * 它将保持低能耗呼吸态一直挂在纽扣身旁，静候玩家读完当前楼层剧情；
   * 玩家点击胶囊主体：**手持板立即原地展开，并自动聚焦滚动到该事件**；
   * 玩家点击末尾微小的 `[ ✕ ]`：通知胶囊悄然收回纽扣内，转化为纽扣上的未读数字角标 `[ +1 ]`。

### 3.2 多条通知（Multiple Notifications）全景解决方案

在复杂战况下，LLM 单楼可能同时输出多项变故（如：1条商路遇袭、1条势力态度转变、1条任务推进）。本设计案制定了一套完整的**排队、分级、轮播与风琴展开机制**：

```
                      多条通知输入 (单楼配额至多 5 条)
                                     │
                                     ▼
                      ┌─────────────────────────────┐
                      │    严重度优先队列排序引擎   │
                      │ 🔴 CRITICAL > 🟡 WARN > 🟢 INFO│
                      └──────────────┬──────────────┘
                                     │
                ┌────────────────────┴────────────────────┐
                ▼                                         ▼
      【模式 A：战术平滑轮播】                  【模式 B：风琴层叠抽屉】
   (默认单行低打扰，自动/微操)                (鼠标悬停/轻触，完整展开列表)

   ┌───────────────────────────┐         ┌───────────────────────────┐
   │ 🔴 资金链受损 -150   [1/3]│         │ 🔴 废料商路遇袭 (-150/d)  │
   └─────────────┬─────────────┘         ├───────────────────────────┤
                 │ 5秒自动平滑淡入       │ 🟡 荒原商会态度转为冷淡   │
                 ▼                       ├───────────────────────────┤
   ┌───────────────────────────┐         │ 🟢 弹药制造厂完工交付     │
   │ 🟡 发现新势力接触   [2/3]│         └───────────────────────────┘
   └───────────────────────────┘          单行 24px，纵向扇形展开，点击任一条直达
```

#### 规则 1：硬编码配额与严重度优先队列
* 遵从系统案 **Q9 决策**：单楼事件上限硬编码为 **5 条**，超额隔离；
* 系统内置优先级比较器：
  $$\text{Priority: } \text{CRITICAL (严重破坏/断流)} > \text{WARNING (轻度受损/敌意上升)} > \text{INFO (常规生产/情报归档)}$$
* 收到多条通知时，队列自动按权重重排，**首帧永远呈现危害度最高的事件**。

#### 规则 2：模式 A · 战术平滑轮播（Ticker Mode）
* **微缩翻页指示器**：在胶囊右端显示极简角标 `[ 1/3 ◀ ▶ ]`；
* **低速静默轮播**：
  * 每隔 **6 秒** 垂直轻滑切换至下一条（采用丝滑的 300ms 纵向位移与淡入淡出）；
  * **防打扰停滞**：一旦用户鼠标悬停（Hover）在胶囊上，轮播立即暂停，移开后恢复；
* **微操按键**：用户可点击小三角 `◀` / `▶` 立即手动翻看上一条/下一条。

#### 规则 3：模式 B · 风琴层叠抽屉（Fan-out Stack Mode）
* **展开契机**：
  * 玩家悬停在多条指示器 `[ 1/3 ]` 超过 300ms，或点击胶囊上的展开小图标；
* **形态展现**：
  * 胶囊向下平滑“扇形展开”（Fan-out），展开成一个包含 2~5 行的**轻量挂起抽屉**；
  * 每一行高度仅 **24px**，左侧保留红/黄/绿指示点，右侧为单行文字摘要与数值增减；
* **独立条目点击直达（Focus Jump）**：
  * 点击风琴抽屉中的任意一行，手持板展开并**直达目标页签**，同时该事件卡片呈现 1 秒的热线呼吸边框（`Hot-pulse Border Animation`），向指挥官清晰指引变动根源。

#### 规则 4：批量处理与 Swipe 槽位瞬时隔离
* **一键消减**：风琴抽屉底部提供一个微小的 `[ 全部已读 ]`，点击后抽屉与胶囊瞬间缩回；
* **Swipe 切页隔离铁律**：
  * 通知状态机与当前楼层消息变量（Message Variables）的 `stat_data.events` 强绑定；
  * 当用户在酒馆点击 `Swipe`（左右切页）或回退楼层时：
    * **旧分支的所有挂起通知瞬时作废清空**；
    * 重新按当前新分支的数据重新生成通知胶囊；
    * 绝对禁止将上一分支的“商路遇袭”幽灵通知残留到新分支中！

## 四、前端技术架构与同胞绑定规范

### 4.1 组件树架构设计（零重复轮子）

├── shell.ts                       # 宿主几何、停靠与拖拽基座

### 4.3 独立状态与持久化契约

```typescript
/** pdaState.ts —— 手持板专属状态接口 */
export interface PdaPersistentState {
  x: number;                       // 宿主视口 x 坐标
  y: number;                       // 宿主视口 y 坐标
  collapsed: boolean;              // true: 收纳纽扣态; false: 展开手持板态
  pinned: boolean;                 // 是否固定防误触拖拽
  dockSide: 'left' | 'right' | 'free'; // 智能贴边倾向
  activeTab: 'events' | 'cash' | 'intel' | 'quests'; // 当前激活页签
  readEventIds: string[];          // 已读事件 ID 集合 (随楼层哈希清理)
}
```

* **独立存储键**：`localStorage['tavernweave.pda.state']`；
* **越界防御**：每次从存储恢复坐标时，执行与 `shell.ts` 相同的 `clampPosition` 视口越界拦截，确保无论窗口如何缩放，纽扣与 PDA 永远可见。

## 五、中控台联动彩蛋：机柜顶栏快捷呼出
