## 第一部分 · 卷首与总纲

### 1.1 T3 是什么

T3 的分界线**不是"更先进的现代武器"**，而是战争形态、工业体系与空间尺度的结构性跃迁：

- 稳定进入轨道、在轨长期运作；
- 空间基础设施成为军工体系的一部分；
- 地月空间成为新的工业、情报、交通与军事纵深；
- 海、陆、空、天开始一体化；
- T2 初级超级武器获得结构性增强；
- 指挥部开始拥有**改变战略空间**、而不仅是增强单件武器的能力。

一句话总纲：

> **T1/T2 是"藏在山村里的秘密组织"；T3 后期是"地面上大家都知道我们了，但头顶上的东西没人看得见"。**

### 1.2 与 T2 的接口

- T2 已交付的科技基础继续继承；T3 入口仅统一验收五类共同能力槽，具体名称与工程路径由阵营实现。火箭工业链、应用星座、超武两档功率结构等既有成果不因此失效。
- T3 不淘汰任何 T2 内容：老型号通过改造延续，老机娘人格连续。
- 本文档采用**目标态书写**（驾驶员④号裁决）：假设 `tier:3`、事件型标志位、隐藏轴接口、retrofit 机制均可用；当前 catalog 仅支持 T1/T2 的现状不构成设计约束，相关改造统一进 §16 实施依赖清单。

## 第二部分 · 时代边界与三档标尺

### 2.1 T3 天花板画面（驾驶员定调）

- 空天飞机为常态装备（但产量低、发动机娇贵，偏战略资产而非主力）；
- 天基平台为标配；
- 月面有人基地已建成、**地月常态通勤已实现**、月球空间站可有；
- 深空探索全面开始；
- 大型轨道设施使**太空生产基地**正式具备条件；
- **不造太空战舰**（性价比不足，归 T4 暗示）。

## 第三部分 · T3 开放门槛（共同能力槽＋阵营实现）

T3 入口统一验收五类**跨阵营共同能力槽**，不绑定任何阵营的唯一建筑名、研究名或工程路线：

| 共同能力槽 | 共同验收语义 |
|---|---|
| T2 实验/工程转化 | 能把 T2 理论稳定转成可复现的样机、工艺和部队工程能力 |
| T2 顶尖科研/国家工程组织 | 能跨路线统筹顶尖科研、国家工程、事故处置和长期资源调度 |
| 稳定入轨 | 能独立、可复核地把经认证载荷送入有效轨道；不强制特定回收或周转路线 |
| 持续轨道节点 | 有可持续运行、测控、维护并接收任务载荷的轨道节点；不强制科研空间站形态 |
| 地月工程验证 | 完成无人地月工程任务并回传有效遥测；不得借门槛预写月面发现或解锁武器 |

原有五件套保留为**盟军典型实现**，不再是所有阵营唯一名称链：

```
T3 入口（盟军典型） = 战斗实验室
                   + 尖端科技研究院（T2 顶尖建成）
                   + 航天发射设施
                   + 空间站
                   + 地月投送验证（事件型标志位）

地月投送验证（盟军典型） = 可回收火箭工学（重型运力）
                        + 卫星组网应用工学（中继）
                        + 天基资源勘探工学（勘探载荷）
                        + 卫星测控站·深空天线扩展件
  → 月轨简易星座（中继星×2 + 勘探星×1）
  + 无人登月器着陆并回传
```

苏联以四张国家工程卡实现同一组能力槽：**红星科学城激活**（内部继承红星实验设计局与前两类能力槽）、**国家重型航天发射中心**、**轨道重型工程站**、**地月重载工程验证**。具体前置、验收周期与失败代价引用[《苏联科技总设计》](../factions/苏联科技总设计.md) §5，不由本上位文档改写为全阵营标准。

- 条件公开，答案绝不预写（R7）。月面发现走数据层 hidden / 剧情层。
- 五类能力槽必须全部满足，但阵营实现可在频次、运力、组织和节点形态上不同；不得使用已进入 T3 后才解锁的能力构成循环前置。
- 地月工程验证继续作为事件型标志位；具体阵营事件链各自验收。
- **T2 执行尾巴**：盟军无人登月器当前仅叙事挂点、无参数——补齐口径归 T2 层，不影响共同能力槽。

## 第四部分 · 暴露转折机制（T3 世界观核心）

### 4.1 暴露分级表接线

T3 每条候选的暴露代价统一引用 `暴露分级表设计方案.md` 的五级框架：

| 级 | 名 | 一句话 |
|---|---|---|
| EL-0 | 无痕 | 没人知道 |
| EL-1 | 可疑 | 有人嘀咕查不到 |
| EL-2 | 惊动一方 | 地方势力来查 |
| EL-3 | 惊动大势 | 宗门/国家级出手 |
| EL-4 | 位面级 | 世界格局不可逆改变（[R] 不可逆） |

**域修正**：太空＝零观察者域，在轨行为 EL-0；每次地表↔太空穿越是必须付费的暴露窗口。这是 T3"把力量搬到没有眼睛的地方"的数学表达。

### 4.2 暴露转折（驾驶员①号裁决·选甲）

T3 后期"地面基本已暴露"**不是进 T3 自动触发**，而是**绑定具体事件**：

- 触发条件：首次被宗门/国家级观察者确认身份，或首次使用 EL-4 级武器；
- 触发后解锁**"公开化"选项**：地面建筑可不再伪装、全面扩产（§6 地面建筑设计前提）；
- 设计意图：让"暴露"成为有剧情重量的时刻，而非研究完成的自动按钮。

转折后战略形态：地面维持产能扩张（已无需藏），隐蔽重心转移到太空（EL-0 域）与地下（EL-0 域）——藏字诀没有被放弃，而是**换了藏身之所**。

### 7.2 机娘意识上传与躯体再造（T3 最重情感重量的技术）

**核心命题**：既让玩家能"救回"机娘，又让每次救都心疼——**她还是她，但钱包会哭**。

**意识本质**（驾驶员②号裁决·B+C）：
- 通用主干＝**涌现论**：意识是纳米网络运行中涌现的，扫描会干扰原态、映射非完美复制、**物理上不可同时存在两份可恢复人格**；快照只是独一性救援媒介，不是复制模板；
- 世界适配层＝**机魂论**（看世界观）：修仙世界额外有"机魂/引魂入器"解释，赛博世界为义体/意识数字化，低魔世界退化为高精度人格重建 AI。

**代价体系**（驾驶员核心调性：性格不变、脾气不变）：

| 代价 | 程度 |
|---|---|
| 记忆丢失 | 最后一次快照之后的**几天~一周**记忆永久消失 |
| 躯体适应期 | 新躯体需磨合，期间能力暂时下降 |
| 经济成本 | **巨大**（≈造一台新首台载具，"亿点点"花销） |
| 时间成本 | 制造+磨合周期长，非即时复活 |
| 独一性铁律 | 不可复制、不可并行；注入新躯体即擦除/消耗原可恢复快照，试图保留双份＝双意识崩溃 |
| 真正死亡 | 快照被毁+载具被毁＝不可逆；从未快照＝摧毁即死 |

**明确不做**：人格偏移/性格改变（玩家的纠结是"舍不舍得花钱救"，不是"救回的还是不是她"）。苏联克隆线只能复制身体，不得借快照获得可复制的记忆、忠诚或第一人称连续性。

**研究链**：纳米意识映射工学（诊断）→ 意识快照存储工学（备份+保险库）→ 纳米躯体再造工学（再造舱+独一性铁律）。

### 15.2 RA3 隐藏科技机制（已定稿 · 2026-09-02）

#### 15.2.1 基本原则（H1-H11）

| 编号 | 规则 |
|---|---|
| H1 | 隐藏科技是**独立轴**，不等于任何时代层级（T1/T2/T3）；一项隐藏科技同时具备时代坐标（强度）和隐藏标记 |
| H2 | 落地走 **DLC overlay**（混合方案 c）；base catalog 无隐藏条目，安装 DLC 后数据层才有定义 |
| H3 | 玩家体验五步流程：**偶遇 - 获得情报（模糊）- 触发调查任务 - 完成任务·科技揭晓 - 研究/建造** |
| H4 | 情报阶段**只给模糊线索**，不告知具体科技名称；需交由尖端科技研究院分析后给出方向性提示 |
| H5 | 线索获取靠**叙事进程与运气**（你经历了什么决定你能碰到什么），不可主动刷取 |
| H6 | 每个隐藏科技有**独立的调查任务**，任务内容因科技而异（逆向工程/实地搜集/情报渗透等） |
| H7 | 研究费用 = 同档正史科技 **x1.5~2**（逆向工程溢价），研究周期同比偏长 |
| H8 | 防 AI 抢跑**三层防线**：权威名单预注册 + AI 信息源隔离 + 巧合拦截静默吞掉（详见 15.2.3） |
| H9 | 月面发现 / 多世界泄漏只是线索来源**之一**，不是唯一入口；战场缴获、情报截获、研究院意外同为合法来源 |
| H10 | **坦妮娅**走纯剧情触发（英雄单位），不走科技五步流程 |
| H11 | 世界书**不预告**隐藏科技内容（R7 禁剧透铁律继承） |

#### 15.2.2 五步流程详解

**Step 1 偶遇（不可控 · 叙事驱动）**
- 玩家在正常游戏中碰到异常现象（战场残骸异常部件 / 月面能量反应 / 截获不明信号 / 研究院实验副产物等）
- AI 此阶段**不知道隐藏科技的存在**（信息未注入），只描述表层异常

**Step 2 获得情报（模糊 · 只知道有东西）**
- 系统记录一条"情报碎片"；玩家知道捡到了奇怪的东西，但不知道是什么
- 可交尖端科技研究院初步分析（耗时），分析报告给出方向性提示但不揭晓全貌
- 例："该组件采用未知的全频段光学折射原理，与光棱技术存在关联但工作频段完全不同。建议立项深入调查。"

**Step 3 触发调查任务（有条件 · 可能暂时接不了）**
- 分析报告同时触发一条**调查任务**，任务有硬前置门槛（正史科技/建筑）
  - 条件满足 -> 任务可接
  - 条件不满足 -> 任务挂起，提示"当前技术储备不足，待 XX 条件满足后重启"
- 任务内容是叙事性的（实地搜集样本 / 逆向工程 / 派特工获取情报），每项隐藏科技各不相同

**Step 4 完成任务 · 科技揭晓（神秘奖励）**
- 任务完成，正式揭晓科技名称与完整描述
- 隐藏科技从"不可见"变为"可研究"，出现在科技面板
- 此时科技名称/描述才注入 AI 可见范围

**Step 5 研究/建造（与正史相同，但更贵更慢）**
- 正常花钱花时间研究，完成后解锁建造/生产
- 逆向工程溢价：cost x1.5~2，eta 偏长

#### 15.2.3 防 AI 抢跑：三层防线

| 层 | 机制 | 效果 |
|---|---|---|
| **第一层：预注册** | 隐藏科技名在权威名单中预注册，标记 hidden=true | 解析器命中时不当新实体处理，走隐藏科技特殊逻辑 |
| **第二层：信息隔离** | hidden_phase < 3 的科技，名称/描述**不进入 AI 可见的 system prompt / 世界书** | AI 物理上看不到，从源头掐断 |
| **第三层：巧合拦截** | AI 碰巧编出近似名 -> 权威名单匹配命中 -> **不注册 codex，静默吞掉，后台记日志** | 极端巧合兜底 |

#### 15.2.4 数据层表达（目标态）

ResearchDef 扩展字段（需与 MVU 工程协调，归落地依赖清单 第16部分 第 2 项）：

```
hidden: boolean          // true = 隐藏科技
hidden_phase: 0|1|2|3|4  // 0=未发现 1=获得情报 2=任务进行中 3=已揭晓(可研究) 4=已完成
clue_source: string      // 线索来源描述（内部参考，不入 AI 可见范围）
quest_prereqs: string[]  // 调查任务的硬前置（正史科技/建筑名）
```

隐藏科技条目全部走 **DLC overlay**，base catalog 不含任何 hidden 条目。useCatalogStore 合并后，hidden_phase < 3 的条目不进 UI 科技面板。

#### 15.2.5 与月面答案 / 多世界的挂载

- **月面发现**：月面探索是部分隐藏科技的线索来源之一（非唯一）；月面 hidden 答案属剧情层，隐藏科技只是"月面可能产出的奖励之一"
