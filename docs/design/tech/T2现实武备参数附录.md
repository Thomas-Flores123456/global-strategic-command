# T2 现实武备参数附录（事实底稿）

> 用途：为《T2 科技总设计文档》写入世界书提供**现实军备的名称/性能/参数底稿**，写世界书时有据可依。
> 性质：**资料汇编**，非设计定稿；数据来自公开来源（官方 Fact Sheet / 制造商 / 维基 / 行业站）经 EXA 检索。
> 说明：游戏内造价/耗电/研究点为设计域数值，不在本附录；本附录只管"现实对应物是什么、什么性能"。
> 采集时间：2026-09（陆续补全）。⚠ 部分为在研/未定型项目，参数随官方变化。

## 一 · 航天工业线（"火箭的一生"）

### 1.1 推进剂四类对照（决定三档演进的技术底层）

| 类型 | 组合 | 真空比冲 Isp | 关键特性 | 现实用例 |
| --- | --- | --- | --- | --- |
| **可储存自燃（毒发）** | 四氧化二氮(NTO/N₂O₄) + 偏二甲肼(UDMH)/甲基肼(MMH)/混肼-50 | ~280–320s | **常温可存数年、接触即自燃（无需点火器）**、剧毒强腐蚀 | 长征2/3/4、Titan II（混肼-50）、Proton、多数中/苏早期火箭、**液体 ICBM** |
| **煤油（kerolox）** | 液氧(LOX) + 精炼煤油(RP-1) | ~300–340s | 密度高、需即用不长存、结焦（复用需清洗） | Falcon 9、Atlas V 一级、Soyuz、长征6/7 |
| **甲烷（methalox）** | 液氧 + 液态甲烷 | 介于煤油与氢氧之间 | **积碳少→最适合可复用发动机**、比液氢易储运 | **Starship、New Glenn 一级**、朱雀2/3、长征12A |
| **氢氧（hydrolox）** | 液氧 + 液氢 | ~450s（最高） | 比冲之王、但密度极低、深冷易蒸发 | SLS、长征5/7A/8、Ariane 6、New Glenn 上面级 |

**给三档演进的映射结论**：

- **T2 基础·毒发**：靠"可储存自燃"这一条属性——弹体里灌满推进剂能**待发数年随时点火**，这正是**洲际弹道导弹常备待命**的技术根。一开此档，战略核投送 + 天基侦察同时进场。剧毒/腐蚀/发射暴露是其代价。
- **T2 中期·无毒**：转向煤油/甲烷/氢氧，性能更高、地面处理更安全（去掉肼类剧毒），支撑中/重型运载与卫星星座部署。
- **T2 顶尖·可回收**：**甲烷因积碳少最利于快速复用**（Falcon 9 已用煤油实现回收，Starship/New Glenn 走甲烷）。一级垂直回收→单位入轨成本骤降→空间站模块化发射成为可能。

> ⚠ **一个必须写进世界书的技术真相**：现代美军 ICBM（民兵III、新一代哨兵）用的是**固体推进剂**，不是液体毒发。固体同样"可储存、即射"，且更安全好维护，所以美国 ICBM 早就固体化了。**液体毒发（UDMH/NTO）主要是早期火箭、苏联 ICBM、以及部分航天运载的路子**。给游戏叙事的处理建议：把"毒发"定位为**航天/火箭工业的历史起点与苏联核力量底色**，美系 ICBM 可走"固体化"的差异化描述，避免与现实脱节。

### 1.8 海上发射平台（“发射=暴露”的世界观解法·最关键一条）

**Sea Launch / LP Odyssey（海上发射平台）**：

| 项 | 参数 |
| --- | --- |
| 本体 | 自推进**半潜式移动发射平台**，由海上石油钻井平台改造（1997） |
| 尺寸 | 长 133m、宽 67m、排水量 30,000t（空）/ 50,600t（下沉） |
| 配套 | 与总装指控船 Sea Launch Commander 协同；平台带环控机库运输时存火箭 |
| 发射地 | 赤道太平洋 154°W、距基里巴斯约 370km 的国际水域 |
| 流程 | Long Beach 组装→平台航行 ~4,800km（~11 天）→压载至 22m 吃水→火箭竖立→**船员撤到指控船（5km 外）→平台无人状态下加注与发射** |

**赤道海上发射的现实优势**（可直接写进世界书）：

- 赤道自转速度最大→额外“提速”；无需变轨面→对 GEO **比卡纳维尔尔多多投 17.5–25% 质量**；任意倾角可达。
- 海上发射“远离人口/城市、无射向冲突、几无船舶与空中交通”——安全 + 环保 + **隐蔽**。
- 中国 2019 起已从海上平台发射十余次（现实已常态化）。

**用法**：“平台无人化发射、船员撤至远处、远离人口与航道”这些现实细节，既服务现实感又完美契合“发射=宇宙级暴露→藏到海上去发”的世界观：把发射场搬到海上无人区，是现实与隐蔽逻辑的双重成立。“海权=航天权前置”在此落实。

- 中国 PLA 已向高原部队（西藏/新疆 4,500–5,500m）选装；CASIC“便携弹药支援”（2021）：电机驱动+可换电池，**+44 磅提升、<40 秒穿戴、卸载 >50% 负重**，单兵背 110 磅弹药箱。
- 全身外骨骼：碳纤/铝框 <55 磅，88 磅臂助力 + 132 磅腿支撑，持续 220 磅（短时 440 磅）；用电动工具电池供电；单兵负荷 +110–176 磅。
- 美军：TALOS（战术突击轻型作战服，SOCOM 2013–2019，已停但孕育后续）。

**用法**：“外骨骼开始走进现实”（驾驶员原话）。现实以**后勤/后送/高原负重**为主（非钢铁侠战斗），可作游戏“外骨骼步兵”的现实底；搭“动力外骨骼工学”研究 + 兵营出人。RA2 动力装甲则往科幻端拔高。

## 七 · 工业基础线

> 设计定位：T2 工业线＝“能源换代”。现实能源正从“集中式大电站”走向“工厂预制、模块运输、前沿部署”的小型核能，恰好对接世界观“地下基地/隐蔽据点也要稳定大电力”。灵沁油属虚构，是科技×修仙的能源交汇点。

### 7.1 SMR 小型模块化反应堆（小型模块化核能工学·T2 基础能源）

| 项 | 参数 |

### 7.4 灵沁油完全精炼（虚构·科技×修仙能源交汇）

- **灵沁油完全精炼工学**：无现实武备对应；承接世界书“灵沁油活性组分完全分离需战斗实验室·T2”的既有伏笔。技术可信度参照方向＝石油分馏/裂化、同位素分离、稀有元素提纯——把“修真灵材”当“可工业精炼的能源原料”处理，是本世界观“科技吃掉玄学”的招牌交汇点。
- 与同位素电源 RTG（世界书 #75，已 T1）、SMR、微堆、聚变构成 T2 能源梯队：**RTG（涓流/无人）→ 微堆（前沿便携）→ SMR（基地主力）→ 聚变（尖端）**，灵沁油则是“修真侧”的平行能源支线。
