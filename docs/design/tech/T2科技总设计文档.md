## 第一部分 · 层级哲学与核心原则

### 1.1 三段标尺（已拍板）

| 层级 | 时代基调 | 内容构成 |
| --- | --- | --- |
| **T1** | 千禧年·10 年代（约 2000–2010 定型服役） | 现实货架货 + 红警基础单位。已在世界书中完整落地 |
| **T2** | 现代 + 近未来（约 2015–2035 现役最先进/接近落地） | 现实换代装备 + **红警 RA2 特色实物化** + **航天工业** + **有人-无人协同** |
| **T3** | 空天时代·轨道时代（2035+ 纸面项目与未来概念） | 天基武器/轨道打击/轨道母舰 + 红警终极超武。**门槛=航天发射设施+尖端科技研究院+空间站** |
| **隐藏** | 独立轴（非层级） | **红警 RA3 外挂支线**（雅典娜炮/质子对撞机/光谱塔/冷冻直升机/未来坦克等），特殊条件浮现 |

### 1.2 "下沉一代"原则（已拍板·全面套用）

**核心**：T1 = 上一代，T2 = 当代/次代，制造清晰代差。凡是现实中"最新一代"的装备，从 T1 上浮到 T2，把换代感做实。

**首个具体调整（个人装备线）**：

- **T1 保留 5.56mm 时代**：M4A1、MK18、M249（老 SAW 谱系）、M16 系
- **6.8mm 上浮 T2**：MCX SPEAR(M7)、XM250、XM8 成为 **T2 班组武器换装研究**
- ⚠ **需协调**：《武备·盟军》#2 制式步枪系列现将 MCX SPEAR 列于 T1 基础档、#3 XM250 同样在 T1、#7 弹药表含 6.8mm。上浮需改这三条世界书条目——属**保护清单**，须驾驶员逐条确认。

**原则的延伸效应**：其余线的"当代顶尖"型号同样归 T2（M1E3、伯克 FlightIII、福特级等），T1 顶端型号（M1A2 SEP、尼米兹、伯克 FlightIIA）保持原位作为"上一代天花板"，与 T2 新型号形成代差。**不建议大规模下调现有 T1 型号层级**（触动保护清单成本高），代差主要靠"T2 加新代"而非"T1 降级"实现——唯一例外是已拍板的 6.8mm。

### 1.3 T2 前置深度分层（已拍板）

T2 内部不设子层标签，用**前置研究数量**天然分层：

| 档位 | 前置研究数 | 示例 |
| --- | --- | --- |
| T2 基础 | 2 项通用 | F-22A（低可观测+先进航电） |
| T2 中期 | 3 项（1 通用 + 2 特色 / 或 3 通用） | F-35A（1 通用 + 2 盟军特色） |
| T2 顶尖 | 3 项难前置 + 实物前置 | F-47（3 通用 + F-22 已产） |

### 1.4 无人化 = T2 招牌（已拍板）

**"有人-无人协同"作为 T2 全域主题**，五个领域同步铺开：

- 陆：RCV 无人战车（轻/中/重）、自主补给车队
- 海：LUSV/MUSV 无人水面舰、Orca/Manta Ray 无人潜航器
- 空：CCA 协同无人战斗机（XQ-58A 进化）、MQ-25 无人加油机
- 人员：自主步兵作战平台（TALON 武装放大版）
- 中枢：无人系统指挥中心（新建筑）

这既是现实军事最热趋势，又正落在驾驶员定的"智能化、机械化"方向上。

### 1.5 继承自 T1 的铁律（不变）

1. **首台机娘法则**：每个 T2 新型号首台 = 机娘（独立人格），量产 = 标准纳米体。**每引入一个 T2 型号 = 多一个潜在角色**。无人平台（RCV/LUSV/CCA/UUV）不产机娘（遥控/自主体），是法则的明文例外。
2. **伪装不减反增**：T2 装备更先进，外形伪装更难；雷达隐身对修士的灵气感知无效。
3. **起降/水域/场地约束延续**：世界书既有的起降瓶颈、通航水域、载具容纳约束对 T2 型号同样适用。
4. **双源一致铁律**：前端数据唯一来源是 catalog/$dlc.data，永不解析世界书文本。
5. **命名全局唯一 + MVU 对齐约束**：见第九部分命名自查表。

## 第十一部分 · T3 入口条件（框架·另文细化）

**已拍板**：T3 = 组合条件，T3 = 空天/轨道时代。

**建议门槛组合**：

```
T3 入口 = 战斗实验室（T2已有）
        + 尖端科技研究院（新建筑·T2顶尖建成）
        + 航天发射设施 + 空间站（航天线走完·可回收火箭+在轨组装）
        + 地月投送验证（剧情事件门·已实例化，见下）
```

**地月投送验证（E3 落地 · 2026-09-01 复检设计案兑现）**：

```
地月投送验证 = 可回收火箭工学（重型运力）
            + 卫星组网应用工学（中继技术）
            + 天基资源勘探工学（勘探载荷）
            + 卫星测控站·深空天线扩展件（+500 小成本扩建，不新开建筑）
  → 月轨简易星座（中继星×2 + 勘探星×1；月背通信必需中继）
  + 无人登月器着陆并回传
```

- 对称结构：战斗实验室=T1→T2 之门；空间站=轨道时代之门；**登月=推开 T3 的手**。
- 机制与叙事重合：登月即航天书三项官方留白（天幕结界有无/阵法遮蔽穿透/高阶修士打击轨道目标）的实测兑付点；第一次登月可失败、可撞上意想不到之物——T3 开门是有过程、有风险的主动动作。
- 写入纪律：条件可公开，**答案绝不预写**（月面发现走数据层 hidden/剧情层，R7 禁剧透）。
- MVU 协调追加：登月验证为 T3 条件中唯一**事件型标志位**（非研究完成态），数据层单独建 flag。

**逻辑**：T3 的第一步天然是"走出大气层"——空间站建成即轨道时代开门。这样"航天工业线"不只是 T2 内容，它的终点（空间站）就是 T2→T3 的跃迁通道，与主建筑线的"战斗实验室=T1→T2 通道"形成对称。

⚠ **需与 MVU 工程协调**：`deriveFactionTiers` 当前类型硬编码 `tier: 1 | 2`，推导上限 T2。做 T3 须扩展该函数与类型（`FactionTierInfo.tier` 加 3、补 T3 条件推导）——属 catalog.ts 结构性改动，会影响权威名单取数逻辑。
