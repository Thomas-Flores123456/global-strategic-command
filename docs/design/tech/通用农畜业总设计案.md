## 〇. 立项背景与红线继承

### 0.1 起因

既有《通用·防御辅助》已落盘 `uid 25 生态副食与水循环保障站`（order 40022，driver-accepted）解决**植物性营养**（维生素、膳食纤维、碳水），但**动物蛋白（肉、蛋、奶）、粮食与油料**仍完全依赖外部采购或压缩口粮。对于长期驻扎、编制持续扩张、且未来将纳入生物人类成员的基地而言，"素食基地"在营养与士气两端均存在天花板。

## 1. 第一章 · 总体定位与六大核心原则

### 1.1 与工业基础线的对标定位

农畜业线是与《通用·工业基础》**平级对称**的第二条内生生产线：

| 维度 | 工业基础线 | 农畜业线 |
| :--- | :--- | :--- |
| 线入口 | 矿石精炼厂 | 生态副食与水循环保障站（水培站）|
| 原料获取 | 矿石开采/电子废料回收 | 有机循环/昆虫转化/土壤培育 |
| 终端制造 | 弹药/装备制造 | 食品加工/冷链保鲜 |
| 循环闭环 | 废料→精炼→再利用 | 废物→沼气/堆肥→土壤/饲料→种植/养殖→废物 |
| 外部依赖瓶颈 | 大宗矿石/稀有金属 | 首批种苗/菌种/种畜 |
| 资产性质 | **进攻性**（硬通货与武力）| **防御性**（生存自给与后勤韧性）|

**一句话合同**：工业线让基地"打得出去"，农畜业线让基地"活得下去、藏得住、断供也不垮"。

### 1.2 六大核心原则（写入总则条目）

1. **活得久而非活下来**：压缩口粮续命，农畜业线解决长期营养单一化导致的非战斗减员、士气滑坡与体能衰退。
2. **食物自给＝后勤独立性最终防线**：外部采购渠道被切断时，本线是维持基地长期运转的唯一内生供给。
3. **闭环循环是设计纲领**：每座设施既是生产者也是消费者，废物在体系内不落地、不外运（伪装增益）。
4. **生物系统不可加速**：纳米机械可压缩建造工期，但作物生长、禽畜出栏、鱼类成熟为**生物硬约束**。建成 ≠ 即时产出，须提前数月规划。
5. **反侦察价值**：工业余热经温室与养殖恒温层消纳，把"军用地下高热异常"降格为"常规农业温室排热"——继承既有 uid 25 的核心设定。
6. **外部依赖不可归零**：种苗、种畜、大宗粮谷的初始获取必经外部渠道，是持续暴露源，也是叙事张力与情报渠道价值所在。刻意保留约一成外部通道。

## 2. 第二章 · 经济建模口径（D-AGRI-04 · confirmed）

> 这是本项目对 Gemini 草案**最关键的校正**：农畜业线**不是创收设施，而是进口替代 + 断供韧性设施**。

### 2.1 核心口径：credits=0，进口替代

农畜业设施**不产 credits**。其经济价值由两部分构成，均**不落 credits 账**：

- **进口替代**：省下的外购 `logistics.战备副食与口粮` 的 credits 支出（隐性收益）；
- **断供韧性**：外部采购被切断时维持基地运转的能力（战略价值，不可货币化）。

所有 `<数据>` 块的 `recipes` 一律 `inputs` 无 `credits`、`outputs` 无 `credits`，即 `credits=0`——对齐 `小型纳米合成工坊` 的 `indigenous_synthesis` 本地精炼轨语义。

### 2.2 产出落哪个资源柱（待 §4 细化）

三个候选，倾向**方案 b**：

| 方案 | 做法 | 评价 |
| :--- | :--- | :--- |
| a | 全部回填 `logistics.战备副食与口粮` | 最省，但丢失肉/粮/鱼的品类区分 |
| **b（倾向）** | schema record 开放键新增 `新鲜肉蛋奶`/`原粮`/`鲜鱼`/`饲用虫蛋白粉` 等，per_day 基准 | 保留品类，利用 record 开放键机制，零 schema 改动 |
| c | 新建独立"食物柱" | 🔴 违背"不新增资源柱"红线，否决 |

### 2.3 沼气能源：入 grid_buffer 削峰，不入主网

Gemini 草案称"沼气发电是隐性能源收益"，方向对但未接机制名。**校正**：沼气发电对齐 schema 虚拟能力池 `grid_buffer`（削峰缓冲），**明确不计入主电网稳定发电**——因沼气产出受进料量、发酵温度、季节波动影响，不能作稳定电源。定位是"削峰 + 替代部分电热烹饪"，避免农畜业变成"又产肉又发电"的万能设施。

### 2.4 造价须过定价门

全线造价为**提案值**，须过 `CTRL-ECON-03` 出账三轴（工料当量 G × 复杂度 C × 工期 T）+ 天数带复验。初判：

| 设施 | 提案造价/耗电 | 三轴初判 |
| :--- | :--- | :--- |
| 昆虫蛋白养殖舱 | 500/10 | ROI 最高，大概率成立 |
| 有机循环处理站 | 500/10 | 结构简单，成立 |
| 综合智能养殖场 | 1200/30 | 活体管理+气味封闭，复杂度偏高，待复验 |
| 生态副食站（迁入）| 800/20 | 既有落盘值，迁移不改价 |

## 5. 第五章 · 全链闭环循环模型

```
[工业余热] ──恒温──→ [水培站] ──植物残渣──→ [饲料/昆虫舱/菌棒基质]
     ↑                                              │
 有机肥回灌                                     颗粒饲料/虫粉
     │                                              ↓
[有机循环处理站] ←──粪便/厨余/废弃物──── [养殖场] ──鲜肉蛋奶──→ [食品加工/炊事兵]
     │  ↑                                                              │
  沼气/沼渣  鱼粪/净化水                                          热食/士气
     ↓        │                                                       ↓
[厨房/供暖/削峰(grid_buffer)]  [水产池]                      [指挥官/生物成员]
```

**自给率阶梯（百人编制）**：

- 仅水培站：植物性营养约四成，动物蛋白为零。
- 水培 + 养殖 + 有机循环 + 昆虫舱（**第一版闭环**）：食物自给率约六至七成，饲料外购约四成。
- 全链（+水产+饲料站+加工+土壤+种植+菌类+粮食加工）：约九成以上，外部仅剩少量添加剂与首批种苗。

**要点**：自给率从七成到九成边际成本急剧上升；完全封闭化既不必要也不经济，保留约一成外部通道有利于维持经济互动与情报渠道（叙事价值）。

### B.0 批次三的结构意义与依赖链

Gemini 草案原话点破本批的结构价值：**"从种什么到怎么种之间缺了用什么种"**。水培站跳过土壤直接用营养液，对叶菜微藻可行，但粮食作物（小麦/玉米/大豆）与根茎类（土豆/红薯）在纯水培下产量极低乃至不可行。批次三补齐这条链：

```
[有机循环站沼渣/堆肥] ──→ [土壤站] ──人工基质──→ [规模化种植场] ──原粮/大豆──→ [粮食加工坊]
                            ↑                          │                          │
                       精炼厂脱毒尾渣              秸秆回土壤/饲料              豆粕→饲料站  面粉/油→食品加工中心
```

**三座依赖链（严格串行）**：土壤站（造土）→ 种植场（种粮，唯一基质来源即土壤站）→ 粮食加工坊（把原粮加工为面粉/植物油/薯干，副产豆粕闭合"自产豆粕替代外购"）。

**对 E1 水-食-能三角约束的兑现**：规模化种植场是**耗水与耗电双大户**（滴灌 + 高功率 LED），是 §8.1 E1 三角约束最吃紧的设施——落盘时其 recipe 须显式消耗 `工业与生活净水`，工况须挂 `low_power`。

**经济口径**：三座全部 `credits=0`。种植场全线投产后，养殖场饲料外部采购依赖从约三至四成降至约一至一点五成——**这是农畜业线兑现"断供韧性"承诺的临门一脚**。

本线奉六条原则为纲。其一，所解决者不是活下来而是活得久——压缩口粮可以续命，但长期驻扎、编制扩张与生物成员纳入后，营养单一化必致非战斗减员、士气滑坡与体能衰退。其二，外部采购渠道一旦被切断，本线是维持基地长期运转的唯一内生供给。其三，闭环循环为设计纲领——水培副产物喂养殖、养殖粪便产沼气与有机肥、有机肥回灌种植、工业余热供恒温，每座设施既是生产者也是消费者，废物在体系内不落地、不外运。其四，生物系统不可加速——纳米机械可压缩建造工期，但作物生长、禽畜出栏、鱼类成熟为生物硬约束，建成不等于即时产出，所有设施须提前数月规划。其五，本线具备独特的反侦察价值——工业余热经温室与养殖恒温层消纳后，热成像特征从军用地下高热异常降格为常规农业温室排热。其六，外部依赖不可归零——饲料原料、种苗、种畜的初始获取必经外部渠道，大宗粮谷采购为持续暴露源，自给率提升的极限取决于基地可用空间与能源冗余。

*系统映射：通用农畜业科技线总则 | 研发槽位: 农畜业专属研究槽（线内串行，单队列并发上限1） | 经济口径: credits=0进口替代＋断供韧性，沼气入grid_buffer削峰不入主网 | 指路: 设施实现见本书各条目，跨阵营特色实现见对应阵营武备书*
