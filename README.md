# 全域战略指挥系统

**Global Strategic Command System for SillyTavern / TauriTavern**

欢迎来到统帅部，**指挥官**。

**《全域战略指挥系统》**是一套运行于 **SillyTavern**（Tavern Helper / JS-Slash-Runner）与 **TauriTavern**（ABI v1 原生扩展）的跨位面战略角色卡与前端工程体系。它早已超越传统《红色警戒》题材“造兵营、刷坦克”的早期框架，演进为一座融合了 **90+ 独立心智机娘/舰娘**、**2020s–2030s 次世代现代三军武备**、**现代化重构的三大阵营黑科技**、**从民生环保到星际巨构的立体基建**，以及 **确定性规则结算引擎（MVU）** 的全谱系战略指挥中枢。

在这里，指挥官既能以自然语言推进波澜壮阔的跨界叙事，也能随时展开侧边战术中控台、三环基地沙盘与战术 PDA，亲手调度每一条产线、每一项战略协议与每一位机娘干员。

> 🚧 **开发进度说明**：目前系统的**基地建设、产线调度、11 槽科技研究、30 项战略协议、动态事件、三轨资金链、六柱战略资源、超维暗网与拍卖所、多阵营联席、机娘协同、沙盒自创造物入档及三层剧情记忆**均已开放可用；**工程系统（装备现代化改装与仓段化巨构工程）**与**天基航天玩法**当前尚未正式开放（生产环境默认关闭），正在持续开发中。

### 1. 最亮眼的王牌核心：90+ 独立心智机娘与舰娘体系

- **最高统帅部联席总管“铁三角”（三七分体机制）**：
  三大阵营首发移动基地车（MCV）展开后，七成核心质量锁定为不可移动的建造厂工业母机，三成质量化为可自由活动的人形内务总管：

## 🎮 九大核心玩法深度解析

完整的源码调用链与数据契约详见 [`docs/Architecture/Gameplay Structure/`](docs/Architecture/Gameplay%20Structure/README.md) 系列文档，以下为各大玩法的具体机制说明：

### 玩法一：双宿主运行底座、战前五步部署与楼层卡片水合
>
> 架构详单：[00-共享底座与玩法运行链路](docs/Architecture/Gameplay%20Structure/00-共享底座与玩法运行链路.md)

- **五步开场启动器（`#0` 楼）**：指挥官在开局时自由选择目标位面（赛博朋克 2077、修真正史、赛博朋克 2042 等）、1～3 个首发阵营、开场切入方式（基地已展开 / MCV 车载待命 / 穿越前夕未绑系统 / 指挥官主动通联）与机娘孵化模式，自动完成 35 卷世界书排他同步并锁定 `$boot` 初始快照。
- **S0～S6 确定性结算流水线**：每当新楼层生成或切换 Swipe 时，解析管线依次提取 AI 战报标签、计算跨天工期积分 `Δt`、推进建筑/生产/科研/工程/航天/资金链/暗网状态，并执行**三色对账（Trusted 绿 / Clamped 黄 / Rejected 红）**，将结果写入当前楼层 `stat_data`，天然支持任意删楼与回滚。
- **19+ 类楼层内嵌战术卡片**：AI 输出的 `<战况>` `<队列>` `<事件>` `<工程>` `<航天合同>` `<暗网>` `<资金链>` `<任务>` `<情报>` `<世界演变>` `<机娘档案>` `<阵营解锁>` 等协议块，会被自动水合为精美的 Vue 交互式战术卡片。

### 玩法二：基地建设、三环空间沙盘与产线即时调度
>
> 架构详单：[01-基地建设列装生产与产线调度](docs/Architecture/Gameplay%20Structure/01-基地建设列装生产与产线调度.md)

- **五大建造分类与详情立项**：中控台建造网格按「建筑 / 防御 / 人员 / 载具 / 空天」分类展示，自动隐藏已由基础条目原位继承的升阶包；点击卡牌可在详情抽屉中选择**新建、升阶改建或附属插槽挂载**，并指定地下/地表/高空层位与三环方位。
- **建筑管理三视图**：
  1. **三环雷达坐标沙盘**：以基地车（MCV）为 `(0,0)` 原点，按内环核心区、中环产线区、外环防线区与八方位自动推算相对坐标并渲染战术雷达图，支持编辑模式（`editMode`）直接拖拽移位、切换标准/过载/静默工况或改派产线模式；
  2. **五大体系 Dagre 拓扑蓝图**：按能源、制造、防务、研究、后勤五大体系可视化展示建筑依赖与升级路径；
  3. **多基地分组列表**：实时监控各基地工况、血量、层位与附属件。
- **六动词日程推演与满工时自动入库**：
  - 日程台（`ModalSchedule`）支持**加速、减速、暂停、恢复、撤销、跨基地指派**六大动作，并提供**即时生效模式（`instantMode`）**直接改写本楼队列而无需等待下一轮 AI 回复；
  - 引入**二阶段纳米装配折算**（普通工业段 + 纳米精加工段，按纳米工料库存自动加速或降级施工）與**同车道溢出顺延**（前一单完工剩余的 `Δt` 自动顺延给同车道下一单）；
  - **系统主权自动交割**：队列累计工时达标即由前端自动结项，将新造部队直接并入 `forces` 兵力表、新建筑直接并入 `buildings` 资产表。

### 玩法三：11 槽科技研究、双算力加速与 30 项战略协议
>
> 架构详单：[02-科技研究与战略协议](docs/Architecture/Gameplay%20Structure/02-科技研究与战略协议.md)

- **11 大科研课题组与门禁复验**：涵盖基础建筑、人员、工业、装备、防御、陆具、空具、舰艇、航天、农畜与环保 11 条独立研究槽。每轮结算先复验研发母体建筑是否处于正常运转态（断电、停机、受损、冻结等 10 种非运转态自动暂停推进），再积分工期。
- **双算力（TFLOPS / TOPS）加速与跨厅直跳**：基地内或全战区的超算中心、量子超算中心提供通用算力（TFLOPS）与 AI 算力（TOPS），最高可提供 +100% 研发效率加成；科研面板支持点击缺失前置芯片一键跳转至科技树对应节点。
- **三阵营 9 座院所协同与 30 项战略协议**：
  - 盟军、苏联、尤里各有 3 座 T1/T2/T3 协议锚点建筑（共 9 座），本阵营主建筑每日产出 +1 协议点，已解锁的其他阵营主建筑按 **50% 跨阵营协同率** 折算贡献；
  - 内置 **30 项三阵营战略协议**（每阵营 3 轨 × 4 级 = 12 项，如空域主权、超时空机动、钢铁洪流、心灵谐振等），支持通过 `<事件> 协议排程` 执行加点、排队、改道、暂缓与撤回。

### 玩法四：在役装备现代化改装（V1）与仓段化巨构工程（V2） `🚧 尚未开放 · 开发中`

> 架构详单：[03-现代化改装与巨构工程](docs/Architecture/Gameplay%20Structure/03-现代化改装与巨构工程.md)

- **V1 短期分阶段现代化改装（47 项存量自动升格）**：

- **V2 长期仓段化巨构工程**：
  面向轨道空间站、赤环战略电磁天梯及六大国家级巨构。采用 **DAG 仓段依赖图**，支持为不同模块指派不同牵头基地施工、真实扣减纳米工料库存，并在模块暂停时动态释放轨道/深地准入槽位。
- **多视角 SVG 战术工位场景**：工程弹窗内嵌跨世界书动态加载的 SVG 蓝图场景，支持切换总装车间、轨道天基等视角并高亮当前选中仓段。

### 玩法六：动态事件、多基地局部天候与战术 PDA 悬赏
>
> 架构详单：[04-动态事件与资金链经营](docs/Architecture/Gameplay%20Structure/04-动态事件与资金链经营.md)

- **14 标准事件动词与三轨资金链（`FD-51`）**：
  `<事件>` 协议支持战损、停机、恢复、电力调节、资金链五动词（新增/调整/暂停/恢复/枯竭）、协议排程、建筑状态、副官指派与 MCV 展开/收起。每条资金链可同时配置**系统资金（`rate_daily`）、世界合法外币（`wallet_daily`）与六柱货物吞吐（`resources_daily`）**，当基地原料不足时自动触发欠料停机保护，并拦截把本土贸易误写进系统资金的串轨错误。

- **独立战术 PDA（四大页签 + 15 类任务悬赏）**：包含战区态势、情报档案、世界演变（支持三档反剧透隐身遮罩）与作战任务页签，内置 17 种任务原型与 15 类悬赏奖励交割。

### 玩法七：六柱战略资源、多元资金阀门与跨维暗网拍卖
>
> 架构详单：[05-战略资源回收提纯与经济估值](docs/Architecture/Gameplay%20Structure/05-战略资源回收提纯与经济估值.md) · [10-多元资金体系与跨维暗网交易](docs/Architecture/Gameplay%20Structure/10-多元资金体系与跨维暗网交易.md)

- **六柱物资三态非负账本与纳米 7 档实扣**：
  实时核算工业金属、稀土/特种矿、能源化工、高能晶体/同位素、电子精密件与生物医药六大支柱（严格区分「未探明 / 已探明告罄 / 正常流转」三态，下限锁 0），以及 T1～T3 七档纳米工料库存。
- **五大合法系统资金来源与双轨货币隔离**：
  严格隔离「系统资金（Credits）」与「本土世界外币（欧元/信用币/下品灵石等）」。系统资金仅能通过 **① 矿石精炼厂提纯、② 电子废料回收厂拆解（单厂独立 `+1200/日`）、③ 科技油井/催化裂解、④ 黄金珠宝与高纯金条熔铸商路、⑤ 超维暗网交割** 五大合法阀门获取。
- **跨维暗网终端与每 7 日专场拍卖所**：
  建造 T1【超维暗网中继站】后解锁暗网玩法。支持 **9 大标准交割动作**（直购、售出、情报变现、悬赏完成、拍品上架、参与竞标、专场结算、流拍、**撤拍退库**），每满 7 个游戏日自动轮转专场拍卖会，在资源弹窗「超维暗网」页签与楼层暗网卡片中即可一键挂单、竞拍或撤拍。

### 玩法八：多阵营联席参谋部、暴露度/民心双驱与机娘终端
>
> 架构详单：[07-多阵营联席阵营解锁与机娘协同](docs/Architecture/Gameplay%20Structure/07-多阵营联席阵营解锁与机娘协同.md)

- **1～3 阵营开局折算与局内启封**：支持单阵营精锐开局、双阵营联席或三阵营全开（自动折算初始资金、提升初始暴露度并附加跨阵营磨合期效率修正）；局内亦可通过工程中心立项或剧情 `<阵营解锁>` 启封新阵营 MCV 并动态挂载对应阵营四书。
- **五档暴露度（`EL-0`～`EL-4`）与五阶民心双驱引擎**：根据基地规模、重武器开火与超时空/核能并网动态累积暴露度，驱动本土势力从民间流言逐步升级至国家级围剿；同时结算占领区五阶民心，反馈产线效率与治安事件。
- **机娘四维军备终端（`ModalMechaGirl`）**：
  - 实时切换在编机娘干员，通过 `loadGirlDossierDetail` **跨世界书动态回读每位角色的正史档案**（含外观、性格、作战定位、专属技能与特殊挂载），绝不固定写死单一角色；
  - 对战地盲盒新涌现、尚未写入静态世界书的机娘，自动回退匹配所属兵种母板技能，并支持在楼层卡片中执行**赐名仪式**正式入档。

### 玩法九：沙盒自创造物入档、分支克隆与三层剧情记忆
>
> 架构详单：[08-沙盒造物动态入档与剧情记忆](docs/Architecture/Gameplay%20Structure/08-沙盒造物动态入档与剧情记忆.md)

- **沙盒自创造物全自动入档**：指挥官在剧情中自创的**新科技、新建筑、新载具、新装备、新兵种、新阵营、新 NPC 或新机娘**，经 `<扩展档案>` 输出或 PDA 采纳后，会自动合成标准 `<数据>` JSON 块、双向缝合科技树解锁图谱，并写入当前聊天专属世界书（受三重防污染守卫保护，绝不篡改 35 卷官方母书）。
- **删楼逆向回滚与分支自动克隆**：所有动态写入世界书的条目均记录在每楼 `$timeline.wbJournal` 中；当指挥官删楼重来时自动逆向清理对应世界书条目，切出聊天分支（Branch）时自动克隆独立的 `_branch` 档案书。
- **跨局私产提升与热补丁覆写**：喜欢的自创造物可一键提升为跨存档通用的个人私产（`$promoted`）；剧情中的临时参数微调（`<数据更新>`）存入时间线内存覆写层，跨楼可回溯。
- **小/中/大三层剧情摘要漏斗（Micro / Meso / Macro）**：自动将远古楼层对话浓缩为小总结、中总结与大总结写入世界书并隐藏已归档原楼层（支持删楼时先解隐后删条），配合**跨代角色卡热更新与全保真存档备份恢复**，让数百上千楼的宏大跨界战役始终轻快稳定。

## 🚀 快速开始（游玩方法、开发与世界书检阅）

### 1. 游玩方法（5 步极速上手）

本项目的游玩方法非常简单，只需以下 5 步：

1. **安装插件、导入角色卡与安装依赖**：在酒馆（SillyTavern）中安装 **酒馆助手（Tavern Helper / JS-Slash-Runner）**，并导入本地仓库 [`角色卡/`](角色卡/) 目录下的角色卡（[`角色卡/全域战略指挥系统V1.0.0.png`](角色卡/全域战略指挥系统V1.0.0.png)）；随后在本地仓库根目录中运行 **[`一键安装.bat`](一键安装.bat)** 以安装所有依赖（若本机尚未安装 `pnpm`，脚本会自动为您安装）。
2. **安装同步脚本**：在酒馆助手的脚本页面中，安装本地仓库根目录下的脚本 **[`同步世界书-酒馆助手脚本.js`](同步世界书-酒馆助手脚本.js)**。
3. **一键启动服务**：双击运行本地仓库根目录下的 **[`一键启动.bat`](一键启动.bat)** 即可启动项目（自动完成构建产物自检，并拉起本地静态资源与世界书同步服务）。
4. **打开角色卡**：在酒馆中打开角色卡进入对话。
5. **Enjoy!**

### 2. 前端与结算引擎开发（`mvu指挥系统/`）

需要 **Node.js `>= 20`** 与 **pnpm `>= 9`**：

```bash
cd mvu指挥系统

# 安装依赖
pnpm install

# 运行单元测试 (Vitest)
pnpm test

# 启动本地开发预览
pnpm dev

# 构建生产环境单文件包 (输出至 mvu指挥系统/dist/)
pnpm build
```

### 3. 世界书检阅与校验工具（仓库根目录）

```bash
# 列出指定世界书的全部条目（如《机娘·能力档案》或《武备·苏联》）
node 查看世界书.mjs worldbooks/机娘·能力档案_世界书.json

# 按关键词检索指定条目全文（如查看“白凌”或“M1E3”）
node 查看世界书.mjs worldbooks/机娘·能力档案_世界书.json -k 白凌 M1E3

# 校验全部世界书格式合规性与 <数据> 块 Schema
node 校验世界书.mjs

# 统计各世界书常驻（蓝灯）条目与预算占用
node 统计常驻.mjs
```
